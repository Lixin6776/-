# Qianchuan UI Calibration Notes

记录日期：2026-09-30

## 当前页面结论

千川后台已升级为“千川乘方”聚合页面，旧版计划列表选择器不能直接复用。

已确认的页面结构：

- 计划详情页：`/overall-prom/detail?...&adId=...`
- 计划编辑页：`/uni-creation/overall-live?aavid=...&adId=...&type=edit`
- 编辑页包含“选择抖音号 / 素材设置 / 投放设置”步骤。
- 当前详情页的“更多计划操作”只确认到“编辑”，未确认暂停、启用、删除入口。

## 已识别的编辑控件

编辑页当前存在两个主要数值输入框：

- ROI 目标输入框：当前值示例 `2.6`。
- 预算输入框：当前值示例 `9999999`，单位显示为“元”。

底部操作：

- `保存`
- `取消`

这些输入框使用自定义组件，外层类名包含：

- `ovui-input`
- `ovui-input-number`
- `ovui-custom-input`

## 安全边界

- 校准阶段只打开页面、读取 DOM、打开编辑页，不点击保存。
- 不把旧选择器直接用于新版页面。
- 在正式启用写入前，必须使用一个安全的测试计划完成预览、确认、保存和读回验证。
- ROI、预算修改必须继续经过现有的人工确认流程。
- 暂停、启用、删除、复制、创建和定向等动作需要继续确认新版入口后再接入。

## 下一步

1. 为新版编辑页建立独立的页面适配器。
2. 先接入“修改预算”和“修改 ROI 目标”两个动作。
3. 保存后重新读取详情页，核对预算和 ROI 目标。
4. 再逐步补充素材、定向、排期和其他计划生命周期动作。
