## 0. 一句话总纲

羽川的整套逻辑可以压成一句话：
**全域时代 = 广告池与电商池打通，所有曝光都要花钱竞争，所以「降 CPM、提 GPM」是唯一出路；而这两件事都靠内容/人群资产，不靠调价。**

他的核心公式：
- `ROI = GPM ÷ CPM`
- `ECPM(竞争力) = 出价 × 点击率 × 转化率`
- 全域投放底层是 **OCPM**：本质是花钱买 CPM 曝光 → **CPM 越高，ROI 越低**

---

## 1. 时代与机制（他讲得最多的地基）

- **全域把广告池和电商池打通**，不再分自然流和付费流，所有曝光都要竞争 → **CPM 结构性升高**，纯付费商家最难受。
- 平台考核演变：`OPM / GPM` → `ROI / ROAS`；平台导向从单计划 ROI 转向**整体店铺费比**。
- **乘方 vs 全域**：投直播间差别不大；**投商品卡要重算 ROI（要扣商品佣金）**，新增联盟合作玩法。
- **OCPM 计划自由度低**（目标只能设 ROI）；**品广竞价可做定向、自由度更高** → 他的结论是 **「全域 + 品广」才是当前版本的答案**。
- 电商池看 **GPM（千次曝光成交金额）**，广告池看 **ECPM（预估千次曝光成本）**，两个池子互相影响 → 纯自然或纯付费都活不好。

## 2. 种草与收割（他的第一主张）

- **「只收割不种草，就是自寻死路」**；「全域时代只跑老素材、只做追投」是典型错误。
- **分工**：品广负责**种草**（把新用户变成 A3），全域计划负责**收割**。
- **判断品广有没有用，不看品广自己的 ROI**，要看：① 全域计划有没有变好 ② 人群资产有没有增长。
- **种草 ≠ 花钱买曝光**；种草 = 用户产生 **A3 行为**（停留 3 分钟、互动、转粉、商品点击）。
- **种草成本高 = 蓄水池太小**：全域时代广告池融合，得先靠素材蓄水、对冲收敛，把成交底池做大。

## 3. 素材

- **素材分型**：种草型 / 收割型 / **种收一体型（如 AIGC）**；不同型的目标、出价、模型都不同。
- **全域素材三类**：**主力素材**（维稳）、**先锋营素材**（探索新版图）、**直播画面素材**（收割）。
- **主力素材跑不动消耗 → 看的是点击率和转化率的「增量」，不是绝对值。** 做法：把「养点击率」和「提转化率」的素材从**内容维度拆开**，用点击率素材给转化率素材带增量。
- **素材四象限**：高点击高转化 / 低点击高转化 / 高点击低转化 / 低点击低转化 —— 品牌优先前两类，白牌四类都要做。
- **测新素材**：追投拉不动新素材（低效不可靠）；正确姿势是**小额预算 + 有目标 + 关注过程指标和成交 ROI**。
- **内容决定 CPM**；素材制作公式：**产品 → 场景 → 意图**，层层递进，竞争对象不同、流量价格不同。
- **跨类目**可以降 CPM，但必须同时看点击和转化。
- **短视频占比影响投放效率和直播间稳定性**；只投画面生命周期有限。
- 他的态度：**素材是策略层的事，老板要亲自参与**，不能只当执行层。

## 4. 人群 / 向量

- **素材是常量，人群是变量**；素材带「人货场向量」，向量决定人群标签。
- **降 CPM 的关键是提高人群质量**：5A 资产越健康，流量价格越便宜。
- 人群标签准不准，三个校验口：**直播间大屏的人群×成交数据、素材数据、云图 TGI / 人群对比**。
- 打人群包要抓：基础属性交集 + **内容偏好维度** + 店铺行业下的行为。
- 商品图 / 商品视觉特征也会影响标签与流量（算法提取图片信息 + 用户行为共同决定向量方向）。

## 5. 直播间与承接

- **流量端 ≠ 承接端**：流量端（投手、短视频团队、老板）看**直播时长、单小时观看次数**；承接端（主播、中控、运营、助播、场控）看 **GPM、UV 价值、人均观看次数**。
- **五维四率的正确用法**：把竖向的转化结果**还原成横向的经营过程**（时间轴视角），看真实流动的人，而不是只看最终结果。
- **量与率成反比**；正常直播间的流量曲线是**大周期波浪**，不是心电图式抖动。复盘要结合场观量看率。
- **憋单的本质** = 用话术干预五维四率：提高在线人数 → 提高点击概率 → 提高转化率 → 提高 ROI。（憋单 ≠ 骗人）
- **话术结构由人群资产决定**，不是抄同行：健康人群资产 → 短塑品 / 长报价 / 长逼单；不健康 → **先养后割**。
- 高低客单玩法不同：高客单**长塑品短逼单**，低客单**短塑品长逼单**。
- **直播标准化** = 把直播时间切成多个时段、逐段设计内容以提高效率值；执行先行，再优化话术和素材。
- **别只看大屏整体进人率**（是多渠道平均后的数），要**分渠道**看，找出拖后腿的渠道。

## 6. 复盘（他有一套明确流程）

- **复盘顺序**：先查执行标准（有没有按脚本走）→ 商品大屏（讲解次数、曝光人数、点击率、点转率、GPM）→ 人群大屏（购买人群 vs 观看人群）→ 首购与转粉 → 素材（画面/视频与商品是否相关）。
- **全域 ROI 复盘三维度**：点击率、`CTR × 千次观看`、千次展示 → 分别对应**素材 / 经营效率 / 流量成本**。
- **全域复盘三要素**：CPM、进入率、千次观看。别过度盯进入率而忽略地基和人群。
- 全域复盘归因：先把**承接做稳**、明确直播间能承接的人群，再谈流量问题 —— **流量端和承接端要分开归因**。

## 7. ROI 怎么调

- **不要从低往高拉 ROI**：先定一个合理的高 ROI，再靠数据反推。
- 要看的合理数据：**千次观看、进入率、CPM 千次观看**（重点前两个）。
- **全域跑不动量的两个解法**：① 按 OCPM 机制设定合理 ROI 目标 ② `ROI = GPM ÷ CPM` → **提 GPM 或降 CPM**。
- **全域播不动 ≠ 主播问题**，查运营、产品、素材和跑全域的方式；全域流速本质上取决于 **ROI 是否达标**。
- 高客单人群可以用「+」拉自然流量来降 CPM、提 ROI。

## 8. 起号

- 他的原话态度：**「根本没有什么起号方法论」** —— 起号关键是**直播间的转化能力**，盯 4 个变量：`ROI、千次观看、进入率、千展成本`。
- 底层顺序：**先有成交，才有流量**（先搭鸡窝，再买鸡）。
- 起不来最常见的真实原因：**投放端素材与直播间画面吸引的人群不一致**。

## 9. 品牌 / 价格 / 组货

- 价格差打法：**跨类目赠品**打消价格关注；新赠品用来**做人群外探、跨类目破圈拉新**；**与强品牌联名**占店铺橱窗位做长期访客导流。
- 平台做品牌存在**基因矛盾**（平台要流量规模、品牌要溢价忠诚）；有根的品牌要抓 **产品、内容、私域、品牌触点**。
- 商品卡起步：流量来自货架（猜喜 + 搜索），新品必须靠短视频/直播曝光才被召回进池。
