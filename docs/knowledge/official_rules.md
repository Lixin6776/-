# 巨量千川官方规则速查（官方口径层）

> 来源：巨量千川帮助中心官方文档（2026-10-07 抓取）
> 原文见 `official_docs/` 目录
> **优先级：官方口径 > 用户确认经验 > 外部博主方法论 > 我的推测**

---

## 一、素材追投 / 调控（来自《素材追投调控产品手册》2026-09-19）

### 1. 官方分类
素材追投分两类：**追投** 与 **控成本追投**。
后台看到的「调控预算」「调控状态」「调控中」= **控成本追投**。

### 2. ⭐ 官方给的额度建议（关键数字）
> 官方原文：调控量级太大会和主计划抢量，且会拉低总体账户的 roi，
> 效果很可能不如啥也不调、直接降低主计划的 roi 起量快。

**建议**：
- **控成本追投控制在账户总体消耗的 25% 左右**
- 搜索抢首屏 5% 左右
- 控成本追投预算**更多分配在新素材测试**场景
- 非冲量时间可以少投低 ROI 的控成本任务（可暂停），避免额度花光

> 对照：我们账户实测追投占比 **60%~80%**，远超官方建议的 25%。

### 3. 调控额度规则
- 每日调控总预算（日常额度）**每周一更新**，平台站内信提前通知
- **暂停任务未消耗的预算不再占用**每日调控额度
- 当日剩余可用预算 = 每日调控总预算 − 投放中任务占用 − 已暂停/已删除任务的当天消耗
- 平台额度**不支持单独调高**，大促期平台统一提高

### 4. ROI 达成怎么判断（官方）
- 控成本追投的 ROI 达成，**和计划的累计消耗直接相关**
- 判断标准：**是否达到「10 个转化成本」的累计消耗**
  - 消耗 < 10 × CPA 而 ROI 未达标 → **属产品预期，不用慌**
  - 累计消耗充分但 ROI 仍差 → 提工单排查
- 切换为「净成交 ROI」目标时：**参考系统建议 ROI，对比原支付 ROI 适当下调**，
  设太高会影响拿量

### 5. 不起量怎么办（官方）
1. **预算太低** → 建议按 **10 个转化左右的成本**设置预算
2. **ROI 设置太高** → 参考平台建议出价
3. 要集中拿量 → **提前 30 分钟**创建追投计划，ROI 设宽松一些

### 6. 限制
- 追投任务数上限 **40 个**（控成本/放量、视频/画面共用）
- 每日最多新建 **500 条**
- 成交目标追投：预算 < 5 × 成交成本 无法创建

## 二、成本保障规则（操作红线）

### 调整目标 ROI（来自《全域投放-推直播间产品手册》）
- **调整间隔 ≥ 1 小时**
- **幅度不要超过当前目标 ROI 的 ±10%**
- **两次目标调整间隔需 ≥ 15 分钟**，否则**不享受成本保障**
- 错误示范：每 10 分钟调一次目标 ROI；把目标 ROI 从 3 一下调到 30

### 调整素材
- **不要大量删除！不要立即删除！循序渐进优化**
- 不要骤然删除大量引流短视频创意（会让投放场景剧烈变化，效果波动）

### 控成本追投-自动成本保障（2025/10/18 起）
- 保障周期：任务首次投放起至之后 **1 个自然日**（原 3 天）
- 转化数要求：单个任务转化数 **≥ 10 个**（原 6 个）
- 满足条件 → **T+3 开始收到保障金额**

## 三、指标口径

- **GPM = 千次曝光成交金额**（官方定义，来自《全域投放-推直播间产品手册》）
  - 注：实测大屏 GPM 与「GMV ÷ 千次曝光 × 1000」对不上，推测大屏另有统计窗口，
    以页面值为准，不做反算断言。

## 四、对产品的直接影响（待落地）

| 现状 | 官方口径 | 应改成 |
| --- | --- | --- |
| 追投占比 > 50% 才提示 | 官方建议 **25% 左右** | 超过 25% 提示"高于官方建议"，超过 50% 提示"严重超标、在和主计划抢量" |
| 只看消耗结构 | 官方：ROI 未达标要先看是否达到 10×CPA | ROI 未达标时先判断累计消耗是否 < 10×CPA，是则属正常探索期 |
| 建议"降预算/暂停" | 官方：调整间隔 ≥1h、幅度 ≤±10%，否则不享受保障 | 调整方案要带上"间隔 ≥15 分钟、幅度 ≤±10%"的合规提醒 |
| 建议换素材 | 官方：不要大量/立即删除 | 提醒"循序渐进，不要骤然删除大量素材" |

## 五、素材操作规则（来自《净成交出价-素材评估思路》《GMV最大化逻辑》）⭐

### ⚠️ 最重要：投放中不要删除高跑量低转化素材

> 官方原文：**素材之间相互配合相互影响，不要单一评价素材 ROI**。
> 举例：素材 A 消耗高但 ROI 低、素材 B 消耗低但 ROI 高 ——
> **这可能是结果而非原因**：B 拉高了整体 ROI，让系统有更多下探 ROI 的空间，
> 需要 A 去发挥消耗跑量能力。如果此时删除 A，整体 GMV 会先受影响，
> 且 B 跑量能力弱拿不到更多 GMV，**ROI 也会变低**。

**正确做法**：
1. **不要**贸然在投中删改头部 GMV / 高跑量的素材
2. 素材是否低质，要看**持续多天低跑量**，**不能用单场 ROI 判定**
3. 想刺激某条素材起量 → 用追投**下调 ROI 目标**加速激活，而不是删
4. 持续多天低跑量的低质素材才及时清理（大量低质素材会挤压好素材）
5. 判断素材质量的核心指标是 **GMV / 净成交金额**，不是单一 ROI

### 新素材探索期
- 新素材上传后系统自动探索，**探索期约 3 日**
- 3 日内跑不动属正常，不要急着判失败

## 六、全域投放的本质（来自《直播全域投放有问题怎么调整》）

- 全域投放**不是普通计划**，是"超级计划"，按**整场直播预算**设置
- **唯一原则**：同一抖音号仅允许被一个千川账户用全域投放
- **互斥原则**：全域投放开启后，其他投放产品（专业版/极速版/随心推/搜索/巨量营销/API/浅层目标）**自动暂停**
- **不再拆分"付费和自然"**：要看**直播整体 GMV 和 ROI**，不要单独考核投放直接转化

## 七、问题自查（官方 SOP）

- **内容竞争力**：系统诊断 **20% 以上**由内容竞争力下降导致时，切换标准投放不会有明显改善，
  应优化直播间内容（互动/货品/话术）
- **店铺体验分 < 60 分**会影响投放
- 抖音号禁止投稿 / 全域授权失效 / 账户违规 / 退款关户流程 —— 都会导致跑不动

## 八、指标官方定义（来自《全域投放数据指标说明》）✅

| 指标 | 官方定义 |
| --- | --- |
| 整体消耗 | 全域投放产生的消耗 |
| **整体支付ROI** | **整体成交金额 ÷ 消耗**（每消耗1元带来的成交金额） |
| **整体成交订单成本** | **消耗 ÷ 整体成交订单数** |
| 整体成交金额 | 包含：用户实际支付金额 + 整体成交智能优惠券金额 + 未完结预售订单预估金额 + 电商平台补贴金额 |
| 用户实际支付金额 | 不包含智能优惠券、不包含平台补贴；**旧版"整体成交金额"改名为"用户实际支付金额"** |
| 电商平台补贴金额 | 抖音电商出资的活动（红包/优惠券/秒杀）+ 国家补贴；不含千川智能优惠券、商家/达人出资 |
| 整体成交智能优惠券金额 | 使用「智能优惠券」投放后，成交订单中的优惠券金额 |
| 整体未完结预售订单预估金额 | 预售定金期的系统预估成交金额；尾款期该指标归 0 |

> ⚠️ 官方注：变更后整体成交金额**无法直接与罗盘对数**，要对数请用「用户实际支付金额」。

## 九、追投/调控预算的官方数字（来自《商品投放调控任务说明》）⭐

| 项目 | 官方建议 |
| --- | --- |
| **追投预算** | 不超出计划预算；建议 **计划预算的 20%~25%**，或 **2~10 个转化成本**，或 **500~1000 元** |
| **首测追投预算** | **低于 500 元**，或计划预算的 20~25% |
| **一键起量预算** | 首测 **500~1000 元**，独立预算 **不超过计划预算的 20~25%** |
| **起量时长** | 通常建议 **6 小时左右** |
| 追投预算下限 | **> 100 元**；修改幅度不能小于 10 |
| 时长范围 | 0.5~24 小时，0.5 小时粒度 |
| 推商品追投任务上限 | 每日 **20 个**；单任务最多勾选 **20 个素材** |

⚠️ **风控提醒（官方原文）**：
- 「追投预算需在原全域投放预算之外额外增加，**追投预算越高 ROI 波动可能性越大**，
  且**追投不支持成本保障**，请合理设置」
- 「一键起量预算不支持成本保障」

素材不可追投场景：审核不通过 / 已删除 / 被排除 / **低效素材** / 追投任务已达上限。

## 十、官方「优质直播间」标准（来自《优质直播间规则说明书》）⭐

官方从 **三大维度** 定义优质直播间，可作为直播复盘中「人货场」的检查清单：

### 1. 基础质量
- **声音**：音质清晰无杂音爆音；音量适中；主播语速平稳、咬字清晰、普通话为主；声画匹配无错位
- **画面**：清晰度建议 **1080p**；画面稳定无持续抖动；**整洁无大面积贴纸/字幕/挂件遮挡**；
  光线明亮、无过明过暗；出镜主体（人&商品）轮廓清晰；**无夸张美颜滤镜**影响商品细节

### 2. 人货场匹配
- **出镜主体**：妆容精致、着装得体、造型匹配人设及货品
  （常见人设：素人种草 / 商家带货 / 明星头部 / 专业身份）
- **货品陈列**：摆放整齐、展台干净、有层次感和美感
- **背景布置**：整洁有序、无引人不适内容；与主播形象风格统一；与商品风格和使用场景匹配

### 3. 内容价值 & 交易价值
- **内容价值**：讲解形式多样（平播过款 / 源头直销 / …），内容有用、有趣，
  让用户获取知识、增加信任、感到愉悦
- **交易价值**：商品组合、促销福利、售后保障 —— 优质直播间 **在 ROI、GMV 上更具优势**

> 官方：优质素材会获得**专属流量激励**（引流直播视频体裁激励暂未上线）

## 十一、操作红线补充（来自《全域投放-推直播间产品手册》等 103 篇）⭐

### ❌ 官方明确禁止 / 警告

| 别做 | 官方原因 |
| --- | --- |
| **用「卡预算 / 频繁起停」代替一键控量** | 会导致反复冷启，影响效果 |
| **小额预算多次小幅频繁上调** | 会影响跑量和效果 |
| **骤然删除大量引流短视频创意** | 投放场景会剧烈变化，可能掉量、**ROI 骤跌** |
| **新素材投后短期探索就立即删** | 既付出探索成本，又拿不到正向收益 |
| **随便删头部素材** | 正确做法是「删掉后重新上传测试」 |
| **频繁调控 / 频繁调 ROI 目标** | 前期数据积累阶段效果不稳定属正常，要保持耐心 |
| **设置过大虚假预算（如 99999）** | 有爆量风险，会影响整体 ROI |

### ⚠️ 数据口径坑（重要）

> 官方原文：**使用全域投放的直播场次，抖店罗盘分拆「付费与自然」的流量及成交等数据均不准确，请勿参考**。
> 请关注**直播间整体**流量及成交情况。

### ✅ 有效测试的三个条件（缺一不可）

1. 测试前两天**尽力开播**并**拉长全域投放时段**
2. **减少或不用标准投放**
3. 给系统足够的探索空间，不要潦草测试匆匆放弃

### ✅ 其他要点

- 连续开播时，**要勾选所有开播小时**，不要只勾开播和下播那两个小时
- 全域投放一旦开启，其他投放产品自动暂停；暂停全域后，标准投放需**手动重新开启**
- 直播间内容优化**仍是商家核心工作**，不能只靠投放
