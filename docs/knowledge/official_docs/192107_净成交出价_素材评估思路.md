评估素材思路：素材之间相互配合相互影响，不要单一评价素材ROI，重点关注净成交金额​
核心操作：持续更新优质素材让系统探索跑量，不要贸然删改高跑量低转化素材​
1.
净成交金额最大化逻辑​
•
素材都为整体净成交金额最大化服务​
•
素材之间相互配合，系统自动调控，合力实现更大净成交金额规模​
•
素材之间相互影响，在净成交金额最大化目标下承担各自的责任，不可以孤立评价ROI​
​
2.
操作建议​
•
持续补充优质短视频素材：直播间直投roi高但难以跑量，商家需要持续生产优质短视频素材，系统有更多的探索机会，才能提升跑量规模获得更多净成交GMV！总结高转化/高跑量的亮点元素糅合到新素材上，做好优质素材​
•
投放中不要删除高跑量低转化素材：素材之间相互配合，有的承担跑量责任，有的承担转化责任。投放中删除高跑量素材会导致系统探索范围变小，跑量规模下滑！​
•
及时清理低质素材：持续多天低跑量的低质素材需要及时清理，大盘探索量级有限，上传大量低质素材可能挤压好素材，影响整体跑量规模。​
•
新素材不起量可以做的干预：新素材上传后，系统将会自动探索跑量，探索期为3日左右；对重点素材想刺激起量，可以使用追投工具下调ROI目标加速激活​
•
利用智投星定位素材问题：若素材跑量不及预期，可以在数据模块-素材数据查看整体诊断建议，重点关注表现低于同行的指标，参考同行优质素材优化。也可以输入具体的素材id，让智能星进行诊断，给出优化建议​
3.
常见误区解答​
1.
误区1：单独评估素材ROI，随意删除ROI不达标的跑量素材​
•
举例：素材A消耗高但ROI低、素材B消耗低但ROI很高，简单归因为素材A质量差，系统流量分配逻辑有问题应该给素材B更多流量。​
•
正确理解：素材B拉高整体ROI，才让系统有更多下探ROI的空间，使得素材A有空间跑量。删除素材A会缺少能承担跑量责任的素材，素材B跑量能力弱拿不到更多的GMV。导致净成交GMV规模受损，整体ROI下滑。​
​
2.
误区2：认为直播间直投ROI数据好，不需要补充短视频素材​
•
举例：直投ROI5，短视频ROI3，认为短视频素材转化不如直投画面，依赖直投跑量，短视频素材量极少。​
•
正确理解：直播间直投ROI好，承担提升整体ROI而不是探索跑量的责任。需要持续生产优质短视频，承担探索跑量责任。评价短视频素材质量时，应该放宽ROI门槛，重点关注净成交GMV规模。​
​
3.
误区3：新素材不起量，一定是被老素材挤压了​
•
举例：11月初上传的素材，12月也在跑量；12月上传的新素材过几天就不跑量了，认为被老素材挤压。​
•
正确理解：新素材起量的核心是素材本身质量，如CTR 、CVR、完播率等。初期系统会有扶持帮助素材跑量，后期跑量不足的根本原因是竞争力下滑而不是被老素材挤压。应该关注老素材的亮点元素，优化新素材。​
​
4.
误区4：素材越多越好，都堆上去总是没错的​
•
举例：批量上传几十条相似素材​
•
正确理解：大盘探索资源有限， 堆积低质素材有可能会挤压好素材，反而影响整体跑量。​
