今日头条信息流广告是位于今日头条的新闻资讯和内容流中的广告，广告展示更加原生、匹配用户的浏览习惯。支持多种售卖方式、投放目标，创新互动样式，满足广告主精细化投放诉求。​

产品亮点​
展示原生：信息流广告融合在今日头条优质资讯中，形式原生，用户更易接受品牌信息 ​
创意多元：支持多种创新及互动样式，广告创意无限，有利于进行品牌的多维传播 ​
