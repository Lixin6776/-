一、产品介绍​
1、产品DEMO​
2、产品背景​
        为了满足广告主强势曝光、高效触达的推广诉求，今日头条APP推出创新产品【头条炫屏】，将开屏和信息流完美组合，视频素材从开屏到信息流完整观看，深度触达增加用户，同一时刻加深品牌印象。​
3、产品亮点​
•
优质资源联动​
开屏+信息流强势产品完美组合，满足广告主重大节点大范围传播需求；​
•
沉浸观看体验​
视频素材从开屏到信息流自然续播，流畅顺滑，带给用户更沉浸的观看体验；​
•
强化品牌识别​
核心元素开屏展示，信息流二次展示，同一时刻加深用户记忆，助益品牌认知与回想。​
​
二、产品说明​
1、展示位置​
头条开屏+对应推荐频道信息流广告第四位（这里需要避免描述为4-1，信息流4-1是CPT）​
2、交互逻辑​
•
用户看到【头条炫屏】的开屏广告，如果没有点击开屏跳转，或者没有点击跳过，开屏部分播放完毕后将缩放至信息流进行续播。​
