一、素材追投简介
功能介绍
素材追投支持对指定素材或直播间画面单独设置预算追加投放，系统将依据目标进行额外探索。现平台在已有的素材追投功能基础上，升级支持两种追投方式：1）放量追投（原素材追投）：短时间快速激活素材，在设定的时间段、对素材付出特定预算进行探索；
2）控成本追投（新升级功能）：稳定ROI或成交成本的情况下加速素材探索，支持单独设置ROI或成交目标、且有成本保障（控成本追投根据单独的保障规则提供保障福利，不计入主计划成本保障）。

功能升级点🌟🌟🌟
在原有追投功能基础上，新增“控成本追投”，支持单独设置ROI或成交目标、有成本保障，但有调控预算限额；
支持单独追投直播间画面（“控成本追投”、“放量追投”均支持）；
“控成本追投”支持人群定向（支持年龄/性别/地域/抖音达人/新客定向）；
平台操作升级，新增【调控】页面统一管理追投任务；支持单条或多条素材同时追投、支持投中修改任务（追加时长或预算等）。
适用场景
适用场景：追投调控适用于新素材测试、潜力素材激活、快速刺激流速等多种调控场景。“放量追投”、“控成本追投”各有强项，商家可根据实际需求选择，且可以进行搭配使用（一条素材支持放到多个调控任务、设置不同调控目标）。
如何选择追投方式？1）跑量速度：放量追投>成交>ROI；2）ROI保障效果：ROI>成交>放量追求跑量速度（短时间快速消耗但可能牺牲ROI）——选择放量追投；
追求稳定ROI效果（保障ROI效果、天级稳定拿量）——选择控成本追投-ROI目标；
希望快速适应直播间变化承接跑量（换品/换主播等）——选择搭配控成本追投-成交目标。

注意事项
追投调控需要单独的预算、独立于主计划。假设主计划10w预算，追投2w预算，则账户合计预算为12w（❌而非10w中包含2w追投预算）。请确保账户预算充足，同时避免增加追投调控后超预算。
【控成本追投】可调控预算有上限，规则详见本文3.1模块说明。一旦超过可用预算，则无法新建任务，需调低已有任务预算、或删除不需要的调控任务。
【控成本追投】有单独的成本保障规则，不计入主计划的投放成本保障，请谨慎修改任务，以免失去保障资格。

🤔怎么选择追投方式？

 | “放量追投”和“控成本追投”各有优势，“放量追投”可短时间快速起量、但不保障roi，更推荐在「短时间快速刺激流速」场景；“控成本追投”调控时间稍微拉长、但更有效果保障，更推荐在「新素材测试」等场景。
不同追投目标可以同时搭配使用，一条素材支持放到多个调控任务、设置不同调控目标。
⚠️注意：“放量追投”和“控成本追投”对预算设置的要求不同，放量追投建议小预算+拉长时长，预算过高可能成本波动大，且无成本保障；控成本追投预算勿过低，建议按5-10个转化成本设置，否则可能难起量、探索不到达成转化需要的流量量级。
 | 
🤔“控成本追投”有什么注意事项？

 | 控成本追投创建到起量需稍作等待，若特定时间需要起量、建议提前半小时创建好追投任务。
“控成本追投”ROI可参考平台「建议出价」、略低于主计划。尤其新素材测试等场景，需给到调控任务探索空间，否则可能难以跑量。
“控成本追投”创建后，建议达成一定消耗量级再进行调整（可参考5～10个转化成本）。前期累计消耗较少roi尚未符合预期时，请勿立刻删除任务，建议稍作观察等待。因控成本追投ROI的达成需要一定的探索量级，ROI会随着累计消耗的提升而表现得更好。
“控成本追投”需要规划调控预算，避免调控预算很快花光。为避免影响主计划探索，控成本调控有总额限制（详细规则）。建议：1、控成本追投预算更多分配在新素材测试场景；2、在非冲量时间可以少投一些低roi的控成本任务（可暂停任务），避免额度很快用完。

成本保障规则
“控成本追投”拥有单独的成本保障规则，不计入主计划成本保障，请谨慎修改 追投任务ROI出价 或 定向，以免失去保障资格。
成本保障方式：控成本追投-ROI目标于25年7月11日、成交目标于25年10月18日支持线上自动成本保障。（25年10月前以离线形式支持，平台统一测算金额单独打款到千川账户，标题【资金动态】补量赠款到账通知 ）。
例如，7.11首次投放的任务，7.11开始有成本保障标识，满足成本保障条件的保障到T+1（7.12），T+2（7.13）开始测算金额，T+3（7.14）开始收到保障金额。

常见问题：
什么叫首次投放出去？具体怎么定义成本保障期间？A：追投任务首次产生投放数据，例如，针对ROI出价，计划10.1新建并审核通过，10.2产生投放数据，则成本保障期间自10.2开始计算，及其之后的1个自然日（10.2~10.3）。 

成本保障金额以什么样的形式发放？A：成本保障将以前置赠款的形式发放到巨量千川账户上，在后续账户进行投放的时候可以直接消耗掉，这部分赠款不可申请退款或提现。

任务删除是否影响成本保障？A：针对已经满足成本保障条件的任务，删除任务不影响获得成本保障。

 | 一个素材是否支持支持被选到多个追投任务？支持。
是否可以只单独追投一个素材：支持，但更建议做多条素材的组合追投，比如潜力素材、相同机制的素材、达人的素材等等。仅追投单条素材、和主计划同样的素材只是按不同的出价在pk，如果不是出价有优势会较难跑量。

为什么我无法创建追投/追投失败？原因1：命中不可追投场景：1）视频素材：已删除/审核未通过/排除视频/低效视频/智选视频 不支持追投；2）直播间画面：审核不通过不支持追投；3）追投任务数超上限40个，不支持追投（直播间追投、视频追投共用上限）。
原因2：控成本追投下超过可调控的追投预算，规则详见，需调低已有任务预算、或删除不需要的任务。
原因3：成交目标追投预算设置过低，若预算低于5个成交成本无法创建任务（例如成交出价20，预算最低需20*5=100）。
原因4：每日新建追投任务数过多，平台限制每日最多新建500条追投任务。超过后不可创建。

控成本追投相关

 | Q：为什么要限制调控预算/额度？当前的额度卡控是为投放效果考虑。为了直播间能够实现更充分的流量探索，平台限制了追投可调控的预算上限。调控计划一般比主计划的roi低，所以容易跑得快。但是调控量级太大会和主计划抢量，且会拉低总体账户的roi，效果很可能不如啥也不调、直接降低主计划的roi起量快。建议：1）合理分配控成本追投和搜索抢首屏的额度，建议控成本追投在账户总体消耗的25%左右、搜索抢首屏5%左右；2）控成本追投预算更多分配在新素材测试场景；3）在非冲量时间可以少投一些低roi的控成本任务（可暂停），避免额度很快花光。
Q：是否可以提高额度？平台额度：不支持单独调整，平台在大促期将统一提高额度供大促冲量使用（依据账户历史消耗自动测算），届时将站内信通知。
若您在平台大促周期外，有其他个性化大场冲量的需求，可通过大场直播规划功能提前提报大场额度需求。详见：
Q：为什么控成本追投计划不起量？原因：通常和出价、预算设置不合理相关。
预算太低，建议按10个转化左右的成本设置，预算太小会难起量，探索不到达成转化需要的流量量级，且投中建议监控预算、及时补充。
roi设置太高，建议参考平台建议出价对比roi是否有优势。
此外，如果部分时间段要集中拿量，建议提前30min左右开始创建追投计划、roi设置宽松一些。
Q：为什么“控成本追投”的ROI达成不好？原因：通常和计划的累计消耗还偏低相关。控成本追投的roi达成，会同计划的累计消耗直接相关。部分客户最初会延续历史放量追投的习惯小预算追投，容易最开始探索不够roi没有达成。
处理方式：先看计划是否已达成10个转化成本的消耗判断计划是否已达到所需要的探索量级。
当消耗较少（<10*cpa），roi暂未达到目标、符合产品预期；
当对应计划的累计消耗充分、但是roi达成也不好，可以提工单到雅典娜排查。
Q：为什么切换为控成本追投-净成交ROI目标后，调控跑量下降？原因：通常由于未调整调控任务的净成交ROI目标。
处理方式：切换为净成交出价时，建议参考系统建议ROI，需对比原支付ROI目标适当下调。ROI设置过高可能影响流量获取，导致调控工具效果下降！系统建议净成交ROI = 系统建议支付ROI*直播间或店铺近30天实际的净成交结算率，是切换优化目标后进行合理折算，并不是下调ROI目标。
