一、直播加热有什么价值​
随着闭环电商的发展，直播无疑是绝大部分商家最重要的转化场景之一。而随着直播场景营销的深入，很多商家反馈会面临多种投放痛点：​
•
对于投放新手，投放设置复杂，学习成本高难度大，是否有更低门槛的投放方式？​
•
每个直播间流量承载能力不同，应该投放多少流量进入直播间最为合理？​
•
当前直播浅层产品多，选择困难，不知应该提升哪些互动指标；​
•
是否有更低的拿量成本，更快速的起量产品帮助直播间人气进一步增长？​
•
浅层目标人群效果不佳，如何再投放浅层获取到更精准的人群？​
•
......​
一个好的直播间必然不是通过深层目标永远在转化，通过浅层目标引入「新」的流量，持续的人群破圈带来新增人群才是可持续的生意模式。​

有效看播次数​
​
	
在一次展示中，若用户出现一种或多种直播间互动行为（包含：商品点击、购物车点击、直播间评论、直播间停留），则将本次展示记为一次有效看播。一次投放展示，最多带来一次有效看播次数​

有效看播成本​
	
每带来一次有效看播的成本。计算公式为总消耗/有效看播次数​

有效看播率​
	
有效看播次数占比总展示次数；计算公式为：有效看播次数/投放总点击次数​
