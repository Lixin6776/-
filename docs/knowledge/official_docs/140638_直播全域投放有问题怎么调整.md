一、产品注意事项​
1.
全域投放不是普通计划！​
◦
全域投放负责整场直播的投放，不是一个简单的普通计划，相当于是一个“超级计划”，所以请按照整场直播预算设置全域投放预算。​
2.
唯一原则：同一抖音号，仅允许被一个巨量千川账户使用全域投放投放​
◦
全域投放能力为高度自动化且智能的投放能力，同一直播间的所有投放，仅需通过一个千川账户，新建一次全域投放即可实现，不允许多账户投放。该账户可以是官方账户，也可以是官方账户授权的其他自运营或合作达人账户。​
3.
互斥原则：全域投放一旦开启，标准投放等其他产品的直播投放将自动暂停​
◦
由于产品能力特性，需要从直播间整体对成交进行优化把控，因此除全域投放优化产品外，如果同时使用其他非全域投放的投放产品，均会干扰对直播间成交的整体优化（包含但不限于巨量千川专业版/极速版/随心推/搜索/巨量营销/API/浅层目标等所有投放渠道，品牌投放除外）​
◦
因此全域投放一旦开启，其他非全域投放产品的投放将立刻暂停。​
◦
（以上为直播场景要求，推商品即原短视频带货不受影响）​
4.
暂停全域投放使用之后，标准投放计划需要您重新手动开启​
5.
整体原则：不再拆分“付费和自然”​
◦
请勿再单独考核投放直接转化效果，请切换到抖音号直播整体视角，观测直播整体GMV和ROI的变化。​
6.
看数原则：全域投放有单独报表呈现投放数据​
◦
全域投放投放数据，通过在数据模块单独新增全域投放模块展示。​
◦
常规呈现投放直接ROI的报表例如首页账户整体数据、数据模块-直播数据、实时概览、今日直播、千川直播大屏、直播复盘、素材分析等均不包含全域投放数据，在使用过全域投放的直播场次无法查看。可使用抖店罗盘直播大屏代替。​
◦
开启全域投放的直播场次，在电商罗盘-直播大屏/直播详情页等页面，将统一展示各渠道的整体流量、成交数据，不再拆分免费/付费。​
7.
定向和创意等产品特殊设置​
◦
定向：仅生效智能定向，不支持手动设置任何定向、、​
◦
创意：直播期间，系统将投放直播间画面和优选主页视频投放​
二、全域投放效果评估正确姿势​
1.
“全域投放”产品的预期效果？​
◦
直播整体支付ROI稳定达成的基础上，直播间整体GMV提升15%-20%（数据源自内测客户的效果中位数，不同客户存在个体差异，以实际测试情况为准）​
2.
“全域投放”产品的效果评估方式？​
◦
效果评估方式：您可对比使用全域投放之前和之后，在整体支付ROI持平的情况下，直播整体支付GMV有无提升。​
评估途径一：直播整体支付GMV可以从抖店罗盘观测得到，直播整体支付ROI可以使用抖店罗盘GMV除以千川总消耗，手动计算得出。​
评估途径二：使用巨量千川-数据-全域投放数据-投后复盘模块，观测使用全域投放投放与非全域投放（使用标准投放或完全不投放）时段，直播整体成交金额和整体支付ROI的变化。​
效果对比怎么用？​
用途1：通过全域投放消耗占比，确定从什么时候起开始切到全域投放，通过观察全域投放消耗占比高(如>80%)的日期的GMV，对比占比低或不用全域投放的日期的GMV，评估全域投放对整体GMV的贡献​
用途2：您可观测使用了全域投放的时段，与使用非全域投放的其他投放方式的时段，以及完全未进行任何投放的时段，“抖音号”或“直播间”的整体ROI或GMV变化，如需对比更加科学，请您自行控制货盘、开播/投放时长等其他变量一致​
（注意，如果您一场直播既使用过全域投放，也使用过标准投放，此时全域投放的效果显著与否，与您使用全域投放为直播间投放的消耗占比强相关，全域消耗占比越高，投放时长越久，说明该场直播全域投放用的越多，全域投放对效果贡献越显著）​
