基础质量​
​
	
声音质量​
​
	
1.
音质清晰：直播间声音稳定，音质清晰，不存在杂音/爆音等情况；​
主播：直播声音平稳清晰，没有沙哑、尖锐等声音问题；​
助播：助播音质与主播比较接近，助播发言与主播相互搭配，没有抢词、同时发声等影响主播信息输出等情况；​
2.
音量：直播间音量适中，声音没有过大/过小问题；​
主播&助播音量接近，助播因离麦克较远声音可以略低，不影响用户感受；​
3.
语速：主播语速平稳，无过快过慢情况，声音咬字清晰，发音准确；​
4.
语义：非特殊场景，主播以普通话为主，用词表达通俗易懂；​
5.
声画匹配度：声音和画面匹配，无声音画面错位问题；​

画面质量​
​
​
	
1.
清晰度：画质清晰，分辨率建议1080p；画面不存在光斑、噪点等问题；​
2.
稳定度：画面稳定，无持续画面抖动影响直播画面信息展示；​
3.
整洁度：画面整洁，无大面积贴纸/字幕/挂件等遮挡；出镜主体（人&商品）无遮挡，信息清晰完整展示；​
4.
色彩曝光：​
◦
光线：直播间光线明亮，无过明过暗问题；出镜主体（人&商品）轮廓清晰；​
◦
滤镜：无夸张美颜滤镜，不影响商品细节展示；​

人货场匹配​
​
	
1.
出镜主体：出镜人妆容精致，着装得体，造型装扮匹配直播人设及售卖货品；​
常见主播人设：​
素人种草：讲解中穿插口语化表达和个人生活分享，真实感/亲和力强；​
商家带货：布景及讲解专业、营销意图明确、服务履约/信用背书强；​
明星/超级头部：自带热点话题及粉丝转化能力；​
专业身份：律师、记者、健身博主、舞者等专业领域KOL，职业背书，真实可信；​
2.
货品陈列：商品摆放整齐，展台干净整洁，物品摆放有层次感和美感；​
3.
背景布置： ​
◦
整洁：背景整洁有序，无引人不适/博眼球等画面展示；​
◦
匹配：​
▪
背景与主播形象风格统一，主体风格鲜明，代入感强；​
▪
背景与商品风格、使用场景匹配，不违和；​

内容价值​
​
	
内容讲解​
	
直播讲解形式多样，内容有用、有趣，让用户观看过程中，可以获取知识、增加信任、感到愉悦，常见形式列举：​
1.
平播过款：​
◦
品类丰富：直播间商品多样，用户可选择空间大，提高购买概率；​
◦
讲解高效：主播讲解高效，聚焦1-3个核心卖点+福利优惠，打爆商品，促成购买；​
2.
源头直销：​
◦
背景布置：在商品源头（如：果园/鱼塘等原产地、仓库/工厂等制作地、门店/卖场等售卖地等）进行直播带货，展示商品生长/生产、采摘/制作、选品/打包/发货的真实过程，代入感强；​
◦
讲解深入：配合源头地的真实可信的布景氛围，结合商品卖点进行深度讲解，强化输出商品品质、性价比等优势，促成购买；​
3.
深度讲解：​
◦
产品测评：通过亲身使用体验、实验测试等方式，针对商品的材质、质量、功效、款式等进行测试评价，真实有代入感；​
◦
教程攻略：通过选购教程、使用教程、制作教程等，对选购该商品的一个或多个关键卖点进行讲解（包括但不限于商品的功效、功能、材质、成分、参数、款式、使用感受等），给出选购方案；​
◦
知识延伸：对商品延伸出来的相关背景知识、成分专业知识、功效专业知识等进行深度讲解/经验分享/科普教学，让用户有知识跟视野上的增长，从而促成购买；​
◦
专业背书：以资深玩家/行业专家/专业质检机构等权威主体身份，对商品特性进行客观评价解说，增加用户的信任度，进而促成购买；​
4.
其他形式：​
◦
通过其他有趣/新奇/吸睛的形式，植入商品信息进行带货，激发兴趣，促成购买。如 ：T台走秀、歌舞表演、书法健身、手工艺、杂技、发布会、生活方式记录等；​

直播交互​
​
	
1.
直播配合：主播讲解真诚热情，助播能在关键节点（如上链接/倒数/补库存等），以合适的方式烘托氛围；​
2.
节奏控场：主播讲解不拖沓，能根据用户的反馈掌控讲解节奏，及时推进，控场能力强；​
3.
答疑互动：​
◦
积极面对用户提问，有针对性的进行解答并延伸讲解，解决用户痛点；​
◦
主动发起趣味性互动，增加用户停留时长：主动提问在线观众、点名积极参与互动的观众等，营造直播间良好互动氛围；​

交易价值​
​
	
商品组合​
​
	
1.
商品多样：多SKU，用户可选择空间大，提升成交概率；​
2.
商品配套：商品配套展示、组合出售，提高客单价；​
3.
价格宽度：价格范围广，满足不同用户的需求和购买力，提高成单机会；​
4.
品牌优势：展示商品品牌背书，增加用户信任；​
5.
价格优势：展现商品的价格/折扣/性价比/优惠福利等，吸引用户促成购买；​
6.
商品跨界：通过一些联名ip、跨界合作等，增强商品的话题性；​

促销福利​
​
	
1.
达人满减/直减/折扣券等；​
2.
限时优惠/限时购/限量购等；​
3.
福袋/红包/抽奖等；​
4.
超值赠品/超级福利款商品等；​

促销话术​
​
	
结合促销福利，通过营销话术，进一步激发用户购买，常见形式列举：​
1.
设置悬念：​
“这款限量版的包包，我们只拿到了10个，我先不上架，等我喊321再抢，大家准备好手速！”​
2.
饥饿营销​
“家人们，这款商品现在下单直降50元，活动只持续10分钟，错过就没有这么大的优惠啦！”​
3.
从众心理​
“已经有500位朋友下单了，大家都这么有眼光，你还在等什么?！”​
4.
福利驱动：​
“现在下单，我们额外赠送价值50元的精美礼品一份，数量有限，先到先得！”​

售后保障​
	
配合商品售卖，直播间提供多种售后保障，如过敏包赔、顺丰包邮、闪电退换等，让客户购买无忧​
