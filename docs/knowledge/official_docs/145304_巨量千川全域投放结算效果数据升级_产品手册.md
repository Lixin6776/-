为什么要升级结算效果指标？​

结算效果​
	
​
​
7日结算金额​
	
7日结算金额 = 整体成交金额 - 7日内的退款金额​
说明:​
①全域投放期间带来的全部成交中，剔除7日退款金额，剩余的成交金额为7日结算金额。​
②消费者支付成功后7天内发生退款，7日结算金额会对应变化，当日订单7日后结算金额稳定。​
③部分退款的订单（如退款20%、退运费等），未退款部分仍会计入7日结算金额计算。​
④仅消费者主动退款的订单不计入结算成交金额，系统原因或商家主动退单都会计入结算成交金额。​

​
​
​
7日结算ROI​
	
7日结算ROI = 7日结算金额  / 消耗​
说明：​
①消费者支付成功后7天内发生退款，7日结算数据会对应变化。​
②预售订单消费者退定金或整单金额，都会在计算ROI时扣除对应金额。​
③仅消费者主动退款的订单不计入结算成交金额，系统原因或商家主动退单都会计入结算成交金额。​
④部分退款的订单（如退款20%、退运费等），未退款部分仍会计入ROI计算。​

7日GMV结算率​
​
	
7日GMV结算率 = 7日结算金额 / 整体成交金额  * 100%​
说明：消费者支付成功7天内发生退款，7日结算金额会滚动更新，数据存在波动情况​
