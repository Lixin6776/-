净成交出价是千川平台新推出的一种出价方式，系统将以净成交ROI为优化目标，实现净成交GMV最大化。坚持使用能降低直播间整体退款率，促进结算GMV增长。​
切换到净成交出价且坚持投放，直播场景下降低直播间退款率5%~15%、提升净成交GMV5%~10%，长期使用提升直播间结算GMV5%~10％（大盘数据仅供参考，以实际投放效果为准）​
新建计划时可设置【净成交ROI目标】；也可以在计划列表页，修改已有计划的出价目标为净成交出价。​
​
正确使用净成交出价：​
•
合理出价：因出价方式调整，目标值也要改变。系统建议净成交ROI=系统建议支付ROI*净成交结算率，并不是下调ROI目标。采纳建议出价，有助于保持投放竞争力。如果设置净成交ROI跟支付ROI一样，可能导致跑量下跌，结算GMV下降。​
•
稳定投放：直播间投放时长最好超过直播时长的一半，且保持预算稳定。​
•
正确看数：切换出价方式后，整体支付ROI不再是优化目标，建议在稳定投放净成交出价至少3天后，关注退款率、净成交GMV、结算GMV、净成交ROI的变化。​

净成交出价是什么​
净成交出价是平台新推出的一种出价方式，系统将以净成交ROI为优化目标，实现净成交GMV最大化。​
名词​
	
含义​

净成交​
	
投放期间带来的全部成交中，剔除秒退订单后，剩余的成交是净成交。（秒退订单”指支付成功后1小时内退款订单）​

净成交金额​
	
净成交金额 = 整体成交金额 - 秒退订单成交金额​

净成交ROI​
	
净成交ROI=净成交金额÷消耗。​

净成交ROI目标出价​
	
平台新增的出价方式，使用净成交ROI目标出价，系统核心优化净成交金额，尽量降低秒退订单的投放花费，让投放后的实际ROI接近设置的净成交ROI。​
