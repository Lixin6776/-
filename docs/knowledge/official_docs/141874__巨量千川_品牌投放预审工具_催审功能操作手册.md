预审工具简介​
『巨量千川品牌投放预审工具』可满足客户物料纠错及结果复用的预审诉求，减少投中/审核/下线问题，辅助客户提高投放效率。​
支持产品​
产品类型：信息流、内容种草、商城、搜索​
投放产品：可选feedslive投放、videolive服务、videolive投放、种草通（不含磁贴）、商城智选、商城首秀、品牌专区（电商版）​
*目前千川支持feedslive投放、内容热推、品牌专区（电商版）、商城智选产品，在预定单/创意创编时进行预审结果复用​
工具能力​
审核结果复用能力：预审审核结果可在正式审核中被部分/完全复用​
注意*（提交预审素材时，🌰需区分不同预审素材名称，预审素材名称相同会导致预审无法提交）​
使用说明与配额限制（2026年8月11日起生效）​
品牌预审工具仅服务于品牌合约投放素材的预先审核，为【品牌合约投放】提供素材预审能力，【非品牌合约投放】素材请勿使用。​
为保障审核资源有效使用，系统将基于账户近30个自然日内是否存在品牌合约消耗或下单记录，匹配对应预审额度：​
1.
若账户近30个自然日内存在品牌合约消耗或下单记录，可继续无限制创建预审配置；为保障资源合理使用，仍建议按实际需求提交，避免浪费。​
2.
若账户近30个自然日内暂无品牌合约消耗或下单记录，每日最多可创建3条预审配置。额度统计包含"新建"和"复制"，不包含编辑后再次提交；每日0点重置，当日额度用尽后可于次日重置后继续使用。​
