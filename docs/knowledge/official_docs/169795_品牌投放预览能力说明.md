品牌投放预览能力说明

分享
前言​
为帮助代理商和广告主在正式投放前确认广告展示效果，品牌投放提供仿真预览与扫码预览两种能力，分别覆盖创意创编阶段与下单审核通过后的效果确认阶段。​
​
💡
如何选择预览方式​
•
创编过程中查看样式与页面展示效果：使用仿真预览。​
•
下单成功且广告审核通过后，在真实客户端环境中查看：使用扫码预览。​
​
仿真预览​
适用阶段：广告创编过程中。​
能力说明：仿真预览用于在创意提交前快速查看创意内容及页面展示效果，便于及时检查并调整投放配置。​
注意事项：仿真预览为模拟效果，仅用于创编阶段参考，最终效果以实际投放为准。​
