一、产品介绍​
1、产品背景​
抖音电商作为全域兴趣电商，而商城是承接电商类商家经营的战略要地。随着商城DAU和GMV的快速增长，越来越多的商家在商城内单独营销的诉求愈加强烈，预计未来3年内商城GMV目标占比将达50%，商家如何在商城内获得稳定的流量等话题是较多客户关注的问题。​
品牌投放接入「商城猜你喜欢」推荐位置的流量，推出保量产品——「商城首秀」，占据商城首页靠前黄金推荐资源，可推商品/直播间，覆盖大促、新品上市等营销活动期间的核心购买用户，满足品牌在抖音商城内品牌宣传诉求。​
2、产品亮点​
✅商城优质资源规模引流：抖音商城首页猜你喜欢靠前优质流量位，货架场优质流量规模化引流​
✅核心购买人群提前锁量 ：资源覆盖营销活动期间“逛”抖音商城的核心购买人群，可提前锁定流量，满足品牌曝光需求​
✅创新样式加深用户心智：产品支持推商品和直播间，商品卡已支持全景图、红包雨蒙层、电商IP等样式​
3、营销场景​
•
推新品：新品营销期间，借助黄金资源点位曝光触达高潜用户，积累新品流量，为新品宣发造势​
•
打爆品：帮助店内优质商品实现持续曝光，结合营销节点进行爆品推荐，提升商品售卖规模​
•
做大促：快速为大促页面引流，通过商城资源承接等形式，强化品牌营销形象，促进交易目标的达成​
