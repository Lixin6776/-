一、产品背景​
背景：当前商家在抖音做直播生意时，通常会通过巨量千川尽可能追求整体生意增长。这种情况下，商家大多考核投放ROI，但其实投放ROI只是一个过程指标，归根结底是要优化整体直播生意，要在满足费比要求的情况下尽可能提升成交额或优化成本。（而对费比的要求，其实就是对直播整体ROI的要求，两者互为倒数）​
基于此，巨量千川最近推出了全新的投放产品——全域投放，覆盖信息流推荐、直播广场等全域流量，直接调控直播整体ROI，相比常规优化投放ROI的产品，全域投放更贴近商家本质的经营目标——直播整体净成交ROI，通过提供「稳定直播整体ROI，最大化GMV」的能力保障经营的确定性，助力商家扩大生意规模。​
名词解释：​
•
投放ROI、直接ROI：=投放GMV / 消耗​
•
直播净成交ROI：= （直播间整体成交金额 - 秒退订单成交金额 ）/ 消耗​
•
费率、费比、投放预算占比：=消耗 / 直播间产生的全部成交订单金额​
