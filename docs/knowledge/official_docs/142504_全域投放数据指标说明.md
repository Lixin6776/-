# 142504_全域投放数据指标说明

整体消耗：​
全域投放产生的消耗​
整体成交订单数：​
推商品下，整体成交订单数为投放期间，投放商品在投放渠道下产生的成交订单数 （包含非预售订单的成交单数和预售订单已完成尾款支付单数，不包含预售订单未完成尾款支付单数及直播间内的商品成交订单）​
​
推直播下，整体成交订单数为投放期间，对应的抖音号下相关直播间产生的全部成交订单数（包含非预售订单的成交单数和预售订单已完成尾款支付单数，不包含预售订单未完成尾款支付单数）​
​
整体成交金额：（统计口径变更）​
全域投放-推商品下，投放商品在投放渠道下产生的全部成交订单金额。​
全域投放-推直播下，对应的抖音号下相关直播间产生的全部成交订单金额。​
说明：​
1.
包含用户实际支付金额、整体成交智能优惠券金额、未完结预售订单预估金额和电商平台补贴金额（如电商平台补贴金额没有具体值，则代表当前尚未统计，请等待数据回溯）​
2.
变更后本指标无法直接与罗盘对数，如需对数请使用“用户实际支付金额”。​
​
整体支付ROI：​
整体支付ROI（投入产出比） = 整体成交金额 / 消耗，即每消耗1元投放费用，所带来的成交金额。​
说明：整体成交金额包含用户实际支付金额、整体成交智能优惠券金额、未完结预售订单预估金额和电商平台补贴金额（如电商平台补贴金额没有具体值，则代表当前尚未统计，请等待数据回溯）​
​
电商平台补贴金额：​
电商平台补贴金额是指由抖音电商出资的活动（例如红包、优惠券、秒杀等），及国家补贴，不包含巨量千川智能优惠券金额、商家或达人出资的活动。​
用户实际支付金额：​
全域投放-推商品下，投放商品在投放渠道下产生的全部用户实际支付金额（包含全部订单的实际成交金额，如果预售订单已完成尾款支付，包含预售订单的实际成交金额；如果未支付尾款，仅包含预售订单的定金）；不包含整体成交智能优惠券金额、不包含电商平台补贴金额。​
全域投放-推直播下，对应的抖音号下相关直播间产生的全部用户实际支付金额（包含全部订单的实际成交金额，如果预售订单已完成尾款支付，包含预售订单的实际成交金额；如果未支付尾款，仅包含预售订单的定金）；不包含整体成交智能优惠券金额、不包含电商平台补贴金额。​
特殊说明：旧版“整体成交金额”改名为 “用户实际支付金额”，数据统计口径不变。​
​
整体成交智能优惠券金额：​
在全域投放中使用「智能优惠券」投放功能后，成交订单中的优惠券金额​
整体成交订单成本：​
整体成交订单成本 = 消耗/整体成交订单数​
整体未完结预售订单预估金额​
投放商品在投放渠道下或对应的抖音号下相关直播间产生的已支付预售类订单，在预售活动定金期的预估成交金额，该指标在预售活动定金期为系统预估的订单成交金额；在尾款期由于预售类订单完结，预售类订单会计入直接成交金额，则该指标会变更为0​
