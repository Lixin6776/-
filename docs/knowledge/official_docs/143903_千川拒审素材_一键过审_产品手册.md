产品介绍：什么是「一键过审」​
​
📌
产品一句话：一键过审是巨量千川联合即创平台，为客户提供的素材过审提效工具。在全域投放场景实现“拒审素材一键修复、快速过审”，促进更多投放素材持续投放与消耗。​
​
一键过审能力目前仅针对全域投放中存在投放审核建议的视频素材，暂不涉及内容/电商审核，更多优化能力升级迭代中。​
​
​
「一键过审」哪里好：更快速、低成本、过审超稳定​
​
📍投放无常...... ​
•
正赶上节点/bigday，头部跑量素材起量后突然被下线，或者出现修改建议跑量出现下滑……​
•
正在基建过程中，素材未过审核，修改起来费时费力，等到改好了流量高峰也错过了……​
•
素材被审核下线，可是不知道具体是因为哪里导致拒审，不知道该如何修改才能通过……​
•
跑量很快转化稳定，但是现在在跑的素材太少了，剩下的素材都没过审，感觉在投素材完全不够！​
​
——用 「一键过审」！！！​
基于视频素材的审核建议，「一键过审」功能自动定位问题点、问题时间，生成新的视频素材以供投放。相比自己手动修复，「一键过审」功能具备：修复时间更短、修复成功率更高、修复质量更稳定​
•
【修复时间】：修复时间≈5-10min，可同时修复多条拒审素材≪手动修复（根据调研数据一般30min起），只能单条修复​
•
【过审效率】：可精准定位具体修复卡点，并提供修复能力，修复后过审率提升至90%+​
•
【修复质量】：针对拒审素材的字幕/口播/画面局部/部分分镜进行一键修复，精细化完成过审改动 ​
