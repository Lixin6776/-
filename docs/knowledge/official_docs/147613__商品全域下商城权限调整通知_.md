常见问题​
1.
巨量千川将于什么时间，开始进行全域商城投放权限调整？​
我们将于5月9日开始，分批启动全域商城投放权限的调整。若你在调整范围内，将会收到巨量千川发出的站内信通知。​
2.
商品卡GMV最高的抖音号是怎么定义的？​
店铺内有商品全域消耗的非人店一体且自运营/官方抖音号，选择投放的商品所产生的商品卡gmv（包含自然转化）会被计算到对应的抖音号下，其中商品卡gmv最高的抖音号会获得全域商城权限。​
3.
作为商家如何知道，自己的全域商城权限会被调整？​
在全域商城权限被调整前的3-7天，被调整的商家，会在抖店/千川站内信收到通知，其中抖店站内信需要商家主动订阅“千川投放”，方可接收到通知。通知内容会明确告知，失去/获得商城投放权限的巨量千川账户/抖音号信息。​
4.
作为商家已被通知在调整范围内，且账户内有在投商品全域但未产生商品卡消耗的计划，会有什么影响？​
•
有人店一体抖音号的商家​
影响一：投放人店一体抖音号的商品全域计划（不含已删除和终止计划）将不可投商城且删除商品卡素材。​
影响二：投放商品卡gmv最高的自运营抖音号的商品全域计划，将自动开启商城投放，获得商品卡流量。​
•
没有人店一体抖音号的商家​
影响一：首个千川直投账户未选择抖音号的商品全域计划（不含已删除和终止计划），将被暂停且不可再开启投放。​
影响二：投放商品卡gmv最高的自运营抖音号的商品全域计划，将自动开启商城投放，获得商品卡流量。​
​
5.
作为商家已被通知在调整范围内，不希望被调整该怎么做？​
收到千川站内信通知后3-7天内，请按照通知内容，用指定抖音号或巨量千川账户创建商品全域计划，并产生商品卡消耗，即可免除调整。若有更多疑问，请联系你的直客销售/千川客服。​
​
6.
作为商家已被通知在调整范围内，但希望将全域商城权限，调整到自主指定的抖音号，该怎么做？​
不支持将全域商城投放权限，自主指定到某一个抖音号。人店一体抖音号/商品卡gmv最高的抖音号，进行商城投放的效果可能更优。​
7.
如果商家是千川新客，全域商城权限受此次调整的影响吗？​
不受影响。全域商城权限仍然会默认给到人店一体抖音号。​
8.
全域商城权限的调整是动态持续进行，还是固定单次调整？​
目前是单次调整。后续平台可能根据实际情况调整，调整前会通知可能被影响的客户。​
