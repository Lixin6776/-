一、产品简介​
👍
一句话介绍：全店托管，是巨量千川推出的一种商品投放产品。系统通过升级「自营和联盟达人自动投放」「智能出价」「打通投放数据」等策略，更高效的为全店商品探索全域流量，GMV最高提升5%-10%。相同投放账户内，全店托管和商品自选可同时使用，不影响商品自选在投商品。​
​
全店托管重磅升级（放量中/不支持加白）new​
此次升级的核心是从「单号单账户」升级为「多抖音号多账户」投放模式，主要带来四项改进：​
① 账户限制打开：升级前仅拥有商城权限的账户才能投全店托管，升级后支持所有店铺绑定账户直接投放。​
② 抖音号覆盖扩大：不再局限于「可投商城」抖音号，账户下全部授权的抖音号（含联盟合作达人抖音号）均可自动参与投放。​
③ 流量分配升级：从"多品单抖音号"升级为"多品多抖音号联合优选"，流量覆盖面更广效率更高，此前难以触达的潜力达人流量也能纳入其中。​
④ 成本优化更全面：达人佣金被自动纳入优化目标，不只优化基础广告投放，整体投放效果更有保障。​
