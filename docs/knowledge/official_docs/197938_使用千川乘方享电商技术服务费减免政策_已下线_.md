前言​
为提升客户投放体验，改善客户经营成本，促进互利互惠，作为一项优惠福利，抖音电商平台及巨量千川平台（以下合称：“平台”）特制定《使用千川乘方享电商技术服务费减免政策》。现将政策规则公告如下：​
一、规则概述​
针对巨量千川账户（下称“投放主体”）使用千川乘方所产生的非特定渠道内的成交订单，抖音电商平台在计算对应订单所属店铺商家需支付给抖音电商平台的电商技术服务费时，将按以下标准执行对应订单的电商技术服务费的实时减免优惠：​
•
非跨境订单：类目费率减免至0.6%，商家需支付的电商技术服务费=计费基数*0.6%​
•
跨境订单：类目费率减免至1%，商家需支付的电商技术服务费=计费基数*1%​
•
若部分商品类目常规费率低于上述减免后费率，则按类目常规费率执行，不享受本减免政策。​
二、政策时间​
本政策自政策发布上线之日起生效，结束时间以平台另行通知为准，请客户及时关注政策变更相关公告内容。​
三、具体实施细则​
3.1 政策覆盖范围​
政策覆盖范围参考如下：​
3.1.1 商家范围：本政策适用于抖音电商平台内除即时零售外的所有处于正常经营状态的抖音电商商家。商家覆盖范围将逐步推进，是否可享受技术服务费减免以实际执行为准。平台将视本政策运行情况、平台策略调整等具体评估即时零售商家或未来新增及调整后商家类型（如有）参与政策条件，如平台拟支持即时零售等商家后续纳入政策范围，则生效时间及具体政策条件以平台另行通知为准。​
3.1.2 订单范围​
使用千川乘方产生且同时符合本政策其他要求的非抖音商城app成交订单，可纳入本政策减免的订单范围。订单是否由千川乘方产生，是否属于非抖音商城app成交订单，以巨量千川平台结合投放时间、订单支付时间等巨量千川的订单投放归因判断逻辑为准。​
3.1.3时间范围​
仅限本政策生效期间使用千川乘方产生且在政策生效期间内成交的订单。​
3.2 减免形式​
使用千川乘方产生的非抖音商城app成交订单，平台在计算商家需支付给平台的电商技术服务费时，将按照上述概述部分约定的减免标准，实时计算减免金额，商家无需提交申请或操作。​
商家应向电商平台足额支付减免后的技术服务费，减免后剩余应付的技术服务费的结算时间、结算方式等以抖音电商平台《商家技术服务费管理规范》及相关技术服务费结算协议、规则为准。​
3.3 特别说明​
3.3.1  若商家同一笔订单已在本政策下减免，则不可在《生鲜类目商家全域免佣规则》与《抖音电商商品卡免佣扶持政策》中二次减免。​
3.3.2 除3.3.1外，若商家同一笔订单已享其他电商技术服务费减免，则不可在本政策中二次减免。​
3.3.3 本政策首次发布后新增的商品展示或交易渠道产生的订单不直接享受本政策。平台将视本政策运行情况、平台策略调整、新增订单成交渠道、订单成交模式变更等具体评估未来指定场景产生订单参与本政策的具体条件，具体以订单结算页面实际展示减免情况为准。​
四、政策要求​
4.1 商家行为规范​
4.1.1 商家承诺如符合本政策要求并实际参与到本政策中，商家将严格遵守平台规则、与平台签署的各项协议及平台规则，诚实信用地参与政策，不实施任何违反法律法规和平台规则的行为，不作弊，不虚假宣传，不侵害任何第三方的合法权益，否则抖音电商平台可拒绝向商家减免技术服务费而无需承担责任，给抖音电商平台或巨量千川平台造成损失的，商家应承担全部赔偿责任。​
4.1.2 如存在以下情况，平台有权暂停商家在该政策下的减免权益：​
 a.商家保证金未足额缴纳或未补缴完成；​
 b.商家订单技术服务费未向平台支付；​
 c.商家或商家关联方存在应向平台支付的费用或损失等情况。​
4.1.3 如商家或者商家商品、商品订单存在如下情况，则无法享受平台技术服务费减免，同时平台有权根据情节严重程度，依据本政策及相关平台协议，对商家及其账号采取相应的管控手段，包括但不限于暂停或撤销享受政策资格、追缴已减免技术服务费、限制商品分享权限及直播权限、封禁账号、限制再次注册等措施。​
 a.在政策进行前或政策进行过程中，商家在交易、维权、营销、诚信经营等各环节出现违反平台协议规则或平台有理由认为其存在潜在风险的情况，包括但不限于：用户投诉商家售假或第三方投诉商家侵权、商家存在虚假交易等。​
 b.商家通过购买、转卖、赠予等非正当方式获取、提供本政策参与资格；商家明知应知或与投放主体共同采取不正当方式获取本政策参与资格或套取平台利益。​
c.商家店铺存在售卖假货等严重违规行为、或店铺处于关停、账户封禁状态，或在政策进行期间出现上述情况的。​
 d.商家或其主播的直播行为及内容（含直播间标题、封面、简介、直播内容等）不符合法律法规和平台规则要求，包括但不限于出现侵害第三方合法权益（如知识产权、人格权、商誉等）的内容，违反广告法、反不正当竞争法及相关规定或平台规则，分享不符合法律要求的商品或服务等。​
 e.商家或其经营商品不满足要求，或者商家以任何不正当手段或舞弊方式参与本政策，不正当手段或舞弊方式包括但不限于：刷单；下载非官方客户端；使用模拟器、插件、外挂等非法工具；注册多个账号；篡改设备数据；恶意牟利等扰乱平台秩序；使用插件、外挂、系统或第三方工具对平台及本政策进行干扰、破坏、修改或施加其他影响及平台认为的其他不正当手段。​
 f.订单为虚假订单、异常退款订单、退货重拍订单等违反法律法规和平台规则的异常订单，异常订单的判断标准以平台判定规则为准。​
 g.产生商品订单的乘方计划存在不合理使用平台调控工具、不合理调整计划投放设置或其他干预正常投放消耗金额及速率的行为，包括但不限于超出调控工具的调控目标频繁使用调控工具，不合理使用工具控制计划消耗速率、小幅度或大幅度不合理控制预算金额、直播营销或商品宣传违规导致投放暂停、非客观原因导致的计划投放周期与消耗金额偏离整体客户数据等。平台将结合行业数据、整体客户/商家数据、历史投放情况等综合评估投放的乘方计划/调控工具是否合理。​
h.商家利用本政策进行违法行为（包括但不限于博彩、诈骗等）。​
 i.商家存在其他违反本政策或平台的相关商家协议、商家规则或其他相关平台规则的行为。​
4.1.4 商家如发生注销、退店，视为商家放弃所有已经享受或正在享受的技术服务费减免优惠，平台无义务再向商家进行技术服务费减免。​
4.1.5 商家理解并同意，数据回传、操作指令执行需要一定时间，订单成交和归因可能存在一定延迟，因技术执行导致的订单错漏，商家同意豁免平台责任。由于系统识别等原因，如平台核算商家技术服务费减免金额有误导致为商家减免的金额超过实际应减免金额的情形，平台有权向商家追回多减免金额的部分。​
