完成有效投放三要素​
•
ROI目标设置：ROI目标设置不超过系统建议（系统建议每日更新），ROI设置越低，拿量能力越强，反之越弱，参考系统推荐设置目标更易起量；​
全天目标ROI：=系统今日预期达成的目标=全天GMV/总预期消耗，不统计一键起量、视频追投等调控工具数据。​
如当天调整过目标ROI，则根据各时段设置的ROI目标计算全天目标ROI。​
•
投放消耗：每天投放直播投放消耗至少200元​
•
投放时长：每天最低投放直播投放的时长不得少于直播时长的一半，建议全天投放​

•
计划列表：每日实时披露截止当前的有效投完成情况，状态每日更新，可根据三要素达成情况做针对性调整；​

有效投放日历：披露近90天内，每日的有效投放完成情况，以及当天三要素的达成情况（ROI目标/投放消耗/投放时长）。​
