为什么大促期间更要启投全域投放？​
•
全域投放能够放大直播间流量。大促期间的流量通常相较日常上升明显，而全域投放能够帮助商家有效利用大促带来的流量，提升更多自然流量，加速大幅提升直播间GMV。​
•
全域投放解放投手去做大促更有价值的事情。全域投放将投手从重复基建的琐事中解放出来，将更多的精力放在大促选品、素材测试、直播节奏配合的研究中，在争分夺秒的大促战场中抢占流量先机。​
•
全域投放能够放大种草人群价值。全域投放和星推搜直品专等产品加持能提升更多GMV，以某星图客户为例，使用全域投放vs标准投放，直播GPM+30%~40%。​
