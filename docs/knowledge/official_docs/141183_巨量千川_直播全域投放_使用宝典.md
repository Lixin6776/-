一、✨先导篇：了解产品（首次使用全域的投手必读）​
1.
为什么全域投放能够带来ROI稳定的同时GMV提升？​
全域投放拥有两大底层先进技术能力，来实现ROI稳定的同时带来GMV提升​
•
OneUplift Model 全域一体化增效模型。这个模型有两大作用，一是付费和自然样本和特征相互感知协同，相互学习，实现相互提升，放大整体生意增量；二是精准预估直播间在各个渠道的自然和付费转化率，原先的自然流量池，系统能够判断到这部分流量不需要付费即可触达，因此也不会收费；只有在自然推荐自身无法获得展示机会时，才叠加付费竞争，保障每一分钱都有增量价值。​
•
OneAICampaign AI单项目托管能力。标准投放下同一个直播间需要多次创建计划，人工搭建各种“素材*转化目标*投放时间”组合计划，全域投放仅需表达一次直播间整体ROI目标，上传全部素材，系统基于AI能力去理解并自动化创编/优选素材/流量预估。​
基于这些领先的技术能力，全域投放作为千川首选产品，可以有效提升全局流量，保障在整体ROI达成的基础上，最大化GMV规模。​
​
2.
全域投放适合哪些客户、哪些直播间使用？​
•
全域投放适用于所有客户，帮助放大生意和提升投放人效。自然内容和经营能力越优，使用全域投放的生意增长越显著​
​
3.
使用全域投放需要注意的事情？​
•
一个抖音号同一时间只能有一个账户开启全域投放。全域投放能力为高度自动化且智能的投放能力，同一直播间的所有投放，仅需通过一个千川账户，新建一次全域投放即可实现，不允许多个千川账户投放同一直播间。但一个千川账户可以投放多个直播间。​
​
•
直播全域投放一旦开启，同一抖音号的标准投放等其他产品的直播投放将自动暂停。​
由于全域投放的优化目标是整体直播间ROI，为了达到稳定ROI的同时带来GMV最大化的投放目的，需要对直播间整体成交进行优化把控，除全域投放优化产品外，同时使用其他非全域投放的产品，均会干扰全域投放效果最优。因此全域投放一旦开启，其他非全域投放产品的投放将立刻暂停。​
需暂停的包含但不限于巨量千川专业版/极速版/随心推/搜索/巨量营销/API/浅层目标等所有投放渠道，品牌合约投放除外。​
