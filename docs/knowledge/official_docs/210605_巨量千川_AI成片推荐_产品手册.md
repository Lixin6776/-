一、「AI成片推荐」是什么​
📌
AI成片推荐，是巨量千川全新推出的自动推送AI成片的素材供给产品；​
商家可以「自主筛选」素材后再投放，高效率获取符合预期的丰富素材成片，提升账户跑量​
产品原理：基于商家已有素材、商品和直播间等信息，依托AIGC视频生成能力和丰富电商广告创意策略，自动生成素材成片，推送至账户，由商家筛选后投放并管理。​

底层生成策略​
	
多样、高优质率的探索型生成类策略​
如剧情前贴、图生视频、爆款素材学习推理等​
	
质量稳定的成熟策略，以混剪类为主​
如通用混剪、黄金前贴复用、个性化智能口播​

使用方式​
	
自动生产->主动推送->商家筛选投放​
系统针对在投商品生产素材后推送至各计划，由客户主动预览、筛选后进行投放；​
素材支持查看内容及投放数据，支持删除​
	
一键开关​
客户在创编页开启后，系统自动生产并实时调整策略；​
系统仅披露高跑量优质素材，暂不支持追投、删除等管理操作​
