二、「标准投放-推直播间」和「直播全域投放」的区别​
区别要点​
	
直播全域投放​
	
标准投放-推直播间​

优化目标不同：全域投放直接优化直播整体投产比，更贴合经营目标​
​
	
目标：直播间整体支付投产比，也就是ROI，公式为（直播间产生的全部成交订单金额 / 消耗）​
等价于投放费比的倒数（消耗 / 直播间产生的全部成交订单金额），如您有明确的经营费比要求，使用全域投放比标准投放更贴合商家的经营目标​
	
目标：在付费流量下获得相应转化（点击/下单/成交/结算等）的成本，或者在付费流量下的投放产出比（投放GMV/投放消耗）​
​

投放效果不同：全域投放能撬动自然流量，带动生意增长​
​
	
不再区分付费和自然流量，优化抖音直播间整体流量（原来的自然流量不会收费，通过撬动更多自然流量带动整体生意增长，自然流量越好，撬动空间越大，生意增长越高）​
	
针对性地优化付费流量​
​

投放设置的差异：全域投放高度自动化，释放投放精力，助力内容打磨​
	
一个抖音号搭建一条“超级计划”，以交付直播整体投产比为目标，投中系统全程调控盯盘​
	
多条计划搭配多种产品组合，精细化投放​
​
※※※注意​
1.
为了保证您的投放效果，系统需要对直播间整体成交进行优化，开启直播全域投放期间，同一抖音号的其他非全域投放是推直播产品的投放将立刻暂停。会暂停的产品包含但不限于巨量千川专业版/极速版/随心推/搜索/巨量营销/API/浅层目标等所有投放渠道，品牌合约投放除外。​
（以上为直播场景要求，推商品即原短视频带货不受影响）​
2.
同一抖音号可以授权给多个账户搭建全域投放计划，但是同一时间内能投放该抖音号全域投放的账户只有一个​
3.
一个千川账户可以同时通过全域投放给多个抖音号搭建计划进行投放​
​
三、全域投放的优势​
优势一：提升GMV​
•
开启全域投放后，直播间不再区分付费流量和自然流量，统筹并布局抖音信息流推荐、直播广场、商城、搜索等抖音直播间全域流量。开启全域投放，在直播整体支付ROI不变的基础上，直播间整体GMV预计提升15%-20%​
优势二：效果稳定​
•
全域投放以「直播间整体ROI」为优化目标，系统会在稳定达成此目标的基础上，最大化提升直播间GMV，当前整体ROI达标率在90%+​
优势三：操作简单​
•
一个抖音号在使用全域投放时，只需要设置一条”超级计划“即可全程投放，计划设置简单，且后续不需要新建计划和过多的操作，由系统全程调配盯盘，大大释放投手精力​
​
（以上数据源自内测客户的效果中位数，不同客户存在个体差异，以实际测试情况为准）​
