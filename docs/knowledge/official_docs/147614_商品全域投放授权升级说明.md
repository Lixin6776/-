什么是「全域投放授权转移」？​
全域投放中需要抖音号唯一性的授权，投放账户中的「官方」抖音号默认拥有全域投放的投放权限，授权转移有两种场景：​
1）目前使用的巨量千川账户可以将自己绑定的「官方」抖音号授权给其他巨量千川账户使用​
2）目前使用的巨量千川账户如果要给「自运营」抖音号或「合作达人」抖音号投放全域投放，需要向该抖音号申请投放权限​
📢 多店铺分别授权 打破投放局限！​
过往推商品场景下，商家给达人抖音号投放时可能会受限，因为达人抖音号可能给多个店铺进行带货，但之前商品全域投放抖音号授权只能授权给单一千川账户，其他店铺因此无法使用该抖音号投放。现针对该情况，授权转移全面升级！​
特别说明：此次升级仅针对一个抖音号下有多个店铺商品的情况，可以分别授权给不同账户，但要注意每个店铺同时段仅可授权一个账户的规则不变哦！​
💡
NEW 商品全域投放授权支持多个店铺分别授权，同个抖音号下有多个店铺商品时，可以分别授权给不同账户！（注：每个店铺同时段仅可授权一个账户）​
❗️达人带货多个店铺时，可以分别授权不同店铺同时投放商品全域投放，实现商品生意最大化拿量​
