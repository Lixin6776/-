一、优质素材标准升级的背景​
•
随着抖音流量机制的升级，好内容、好商品、好服务，三者相辅相成，缺一不可。而在这之中，好内容首当其冲，是激发用户购买的关键，直接决定流量分发与转化空间。此前，优质素材通过扶持用户体验较好的内容帮助广告主和商家获得了更多内容流量机会，但在“广告价值”上的收益有限。​
•
因此，平台对优质素材规则进行了整体升级，让优质素材兼具“生态价值”+“广告价值”，让更多的好内容、好商品被消费者看到，拿到更多流量、更多生意的新增量！​
​
二、优质标准定义重磅更新​
💡
一个公式看懂新优质素材定义​
优质素材= ①满足探索门槛（跑量优） + ②保持内容美学（声画优）+ ③提升互动指标（互动优）​
之前的优质规则为符合美学门槛的、画面优质的素材即为优质素材，新定义下，同时满足跑量优、声画优、互动优的素材才是新优质素材。对比旧规则，新优质素材的跑量能力更佳。​
•
跑量优：素材达到一定vv量级（指视频播放数，消耗约100元），说明其满足素材投放探索门槛，具备持续跑量和带来生意增长的潜力​
•
声画优：与之前的 优质素材规则 要求一致，良好的声画素材能够提升用户的观看感受和消费体验，为素材的长效经营奠定基础，体现了素材的生态价值​
•
互动优：通过完播率/点击率/互动率等指标评估素材的内容吸引力和转化潜力，体现了素材的广告价值​
