一、全域投放核心关注的数据指标：整体成交金额(GMV)​
•
在全域下，每个素材都是为GMV最大化服务的，判断素材质量的核心指标仍是GMV，核心操作仍是提供更多的素材给系统去探索，相信系统会自动放大优质素材跑量，不能贸然在投中删改头部GMV的素材；​
二、全域投放GMV最大化逻辑：​
•
全域投放下，为了达成“整体ROI达标的基础上整体GMV最大化”的目标。素材(包括短视频/直播间画面)之间存在配合互补，系统自动调控，全域下素材的表现会受到：整体目标、素材自身表现、其他素材表现3者共同影响，消耗和整体ROI不能简单理解为这个素材本身的质量，更恰当的理解是这个素材当下在GMV最大化的目标下应该承担的责任；​
举例：素材A消耗高但ROI很低（跑量能力强但roi较低），素材B消耗低但ROI很高（跑量能力弱但roi较高），这种现象可能是结果而非原因——素材B拉高了整体ROI，让系统有更多下探ROI的空间需要素材A去发挥它的消耗跑量能力，如果此时删除素材A，那么首先整体GMV受到影响，因为B跑量能力弱从而拿不到更多的GMV，同时ROI也会变低，有损于最大化GMV的原则；​

三、GMV最大化逻辑下需注意！​
•
合理✅：因为直播间直投ROI好但跑量能力弱，主要承担提升整体ROI的责任，短视频素材能跑量，所以短视频素材可以放宽ROI门槛获得更多GMV，但系统始终是最优解，用最好的组合形式在整体ROI达标的情况下拿到最大化GMV。因为系统需要发挥短视频素材的跑量能力拿到更多GMV，所以客户仍然需要生产大量优质短视频素材用于跑量以获得更多GMV！​
•
合理✅：全域下短视频与直播间画面的GMV等数据统计维度为整体直播间数据，不再拆分付费/自然。所以对比标准投放下各项数据占比可能会发生改变，需切换看数方式；​
•
合理✅：即使在素材整体ROI较低的情况下，也不随便删除头部GMV素材，关注整体直播间ROI达成及GMV提升；​
