2.
全域净成交出价​
净成交ROI出价是全域投放新推出的一种出价方式，系统将以净成交ROI为优化目标，在全域流量下实现净成交GMV最大化。坚持使用能降低直播间/商品的整体退款率，促进结算GMV增长。推直播客群切换到净成交ROI出价且坚持投放，预计降低直播间退款率5%~15%，提升直播间结算GMV5%~10％；推商品客群切换到净成交ROI出价且坚持投放，预计商品退款率下降13%~15%，商品结算GMV 提升11%~13％（内测商家平均数据）。​
降低退款率​
预计直播间退款率降低 5%-15%​
预计商品退款率下降13%~15%​
提升结算GMV​
预计直播间结算 GMV 提升 5%-10%​
商品结算GMV 提升11%~13％​
名词​
	
含义​

净成交​
	
投放期间带来的全部成交中，剔除秒退订单后，剩余的成交是净成交。（秒退订单”指支付成功后1小时内退款订单）​

净成交金额​
	
净成交金额 = 整体成交金额 - 秒退订单成交金额​
