一、产品背景​
为什么做？​
流量确定、消费意图明确​
用户在抖音的“消费意图”十分可观-爱看、爱搜、爱逛，抖音商城日均UV达1.7亿，货架电商份额在加速攀升，货架场GMV增长至占比40%，抖音商城支付用户增长+122%；抖音商城是将抖音流量转化为商家客流的主要场景​
商品卡是货架场商品的核心载体​
更好的价格、更全的货品、更精准的营销可以有效提升转化效率，内容、体验、营销、服务缺一不可；做好货架优化也是极其重要的经营动作，商品卡则是货架场景商品的核心载体；​
商城品广助力用户旅程“看刷搜购”最后一环节转化​
