大盘趋势看，品牌正在加速入局种草通​
种草通合约：成熟产品，从头客逐渐渗透到中腰客户，客户数逐月上涨​
种草通竞价：新产品，中腰客户为主，客户覆盖范围更广，客户ARPU也在逐步提升​
种草通合约&竞价双开：已跑通种草通投放链路的客户，逐渐开启种草通合约&竞价同时投放的模式，无论是种草通合约还是竞价，均能贡献高于大盘的客户ARPU，规模获取A3​
为什么投种草通？​
认可A3价值：A3与品牌生意显著正相关​
A3的定义：在云图O-5A模型中，A3代表「种草人群」。A3人群是对品牌有较高认可和消费意愿的用户群体，是衡量种草效果和效率的重要指标。​
•
A3人群转化率更高：A1-A3人群的成交转化率成倍数增长，A3的成交转化率是A2的4-14倍，是A1的7-26倍​
•
A3能带来更高的生意贡献：A3人群带来的成交GMV，贡献了18%-56%的品牌生意​
•
A3能带来更高的新客贡献：A3人群转化的新客成交人群，贡献了35%-61%的品牌新客​
（数据来源：巨量云图，2023.7）​
不仅大盘趋势如此，单品牌的投放实践也验证了A3对品牌生意的帮助。​
CASE-01 以某日化品牌为例，通过近两年的线上生意走势研判，可以看到A3积累规模与品牌在站内&站外生意趋势基本一致，A3对生意的贡献持续维持在30%以上；同时A3人群对品牌兴趣更深，转化意愿更高，更有助于提升投放效率。​
