A3人群规模：​
周期内达到最深状态为A3的人数，例如近30天，表示30天内人群最高状态为A3的去重人数​
A3渗透率：​
周期内品牌A3人群规模/行业下所有品牌的A3人群总规模​
A3贡献成交占比：​
A3贡献成交人数/本周期成交总人数；其中A3贡献成交人数 =（T-30天最高状态为A3的人数+当月新增A3人数) 交集 总成交人数​
A3流转率：​
统计周期前一天为（O∪A1∪A2）且 统计周期内最深状态为A3状态的人数 / 统计周期前一天为（O∪A1∪A2）的人数​
A3转化率：​
统计周期前一天为A3 且 统计周期内达到A4、A5的人数 / 统计周期前一天A3的人数​

品牌搜索量：​
指时间周期内品牌词搜索次数和非品牌词搜索次数的总和，其中非品牌词只有搜索后展现​
了品牌才会属于品牌搜索量​
​
品牌搜索SOV：​
搜后品牌曝光次数/行业搜索次数​
​
品牌看后搜次数：​
周期内看后搜索次数，看后搜没有时间窗，主要评估的是看和搜之间动作的连续性，看完即搜，可以看1min视频也可以几分钟几十分钟，但是看马上进行搜索，跳开这条视频的搜索，就会评估下否下一条视频的看后搜​

新增A3量​
采用「实时最终触点(last touch)」归因方式，将新增A3的贡献归因给促进人群由非A3状态递进到A3状态的最后1次行为上。例如，「营销点击>=2次」带来一个A3，用户在A营销点击了1次，在B营销点击了1次，将新增A3贡献归因给B营销​

转化人数​
曝光归因7天窗口期的转化人数​
