一、什么是全域投放？​
【推商品-全域投放】探索全局优质流量，包括广告流量与自然流量，以商品整体支付ROI（短视频及商品卡产生的全部成交订单金额 / 消耗）为优化目标，带动商品成交额全面提升。​
【推直播-全域投放】探索全局优质流量，包括广告流量与自然流量，以直播整体支付ROI（直播间产生的全部成交订单金额 / 消耗）为优化目标，带动直播成交额全面提升。​
​
全域投放入口：底部tab「营销推广」->流量推广->新建计划->推商品或直播间->全域投放​
