一.「拿量建议」简介​
•
产品介绍：「拿量建议」是直播全域投放下推出的 出价与拿量建议 功能，系统会根据当前设置的ROI目标和实时竞价情况，预估不同ROI目标在未来时间段的整体成交金额（GMV）和消耗（跑量）提升幅度，为冲量或调整ROI目标提供更多参考信息，您可在该产品提供的建议基础上，根据自己的商业目标和经营需求，灵活决策；​
•
拿量原理：在投放系统中，投放出价越高（ROI目标越低），流量竞争力越强，获得的流量和整体成交金额（GMV）也越多。​

二.「拿量建议」使用介绍​
1.
什么情况下会展示「拿量建议」​
•
投放中GMV增量空间大时：在流量较好时，若降低ROI目标预估能提升10%以上的GMV，平台会显示「拿量建议」；但在流量较差时，若降低ROI目标无法带来正向效果，则不会显示；​
•
直播全域投放积累了一定数据量时：「拿量建议」会基于您近期直播全域投放数据进行模型预估；如果您近期未投放直播全域投放，可以耐心投放1天进行数据积累。​
2.
「拿量建议」可以在哪里获取​
•
修改ROI目标时(创编页、投放页)：在直播全域投放的创编页与投放页中填写或修改全域支付ROI时，如果满足「拿量建议」展示条件，平台会展示预估的三档拿量建议。​

3.
如何正确使用「拿量建议」 ​
•
系统根据您的直播间经营情况和大盘竞争情况，提供三档不同GMV增量对应的ROI目标，您可以结合放量和生意规模需求，合理选择ROI目标，以实现调整后达成更高的跑量和GMV；​
•
调整ROI目标后 请耐心等候1~2h 以观察效果，不建议频繁进行ROI目标变更。如需进行30分钟内的快速起量，推荐配合使用「一键起量功能>>」。​

Q&A常见问题​
1.
拿量建议与平台建议出价的区别？​
•
拿量建议：是一款 出价与拿量建议 的产品，基于您当前的ROI目标和实时竞价情况，系统预估未来不同ROI目标对应的整体成交金额(GMV)和消耗(跑量)的变化，为冲量或调整ROI目标提供更多参考信息，您可在该产品提供的建议基础上，根据自己的商业目标和经营需求，灵活决策；​
•
系统建议出价：是系统基于您历史或相似抖音号数据，给到的合理ROI值，若目标设置高于这个值，会影响系统拿量和有效测试，容易出现整体成交金额和消耗变差情况。​
◦
大促期间流量竞争激烈，为帮助商家合理设置ROI目标，重点提升大促期间的投放竞争力，平台综合考虑以下几点提供建议ROI，客户可根据实际生意目标和投放情况选择采纳：①客户近期实际达成的ROI；②历史和本次大促期客户ROI目标竞争力；③同类目商家平均ROI目标。​
