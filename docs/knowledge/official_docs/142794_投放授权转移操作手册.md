入口和授权​
先了解几个概念：​
1.
抖音号授权——巨量千川账户可以与抖音号建立商业合作授权（授权类型包括自运营和合作达人，对应不同的授权范围），也可以与一个抖音号建立“官方授权”绑定关系。​
2.
投放授权——如巨量千川账户与抖音号存在“官方授权”绑定关系，则该账户默认拥有该抖音号的投放使用和管理权限，该账户可以选择自己使用该抖音号投放，也可以授权给其他巨量千川账户（前提是该账户与抖音号存在自运营或合作达人授权关系）。如巨量千川账户与抖音号存在自运营或合作达人授权关系，可以向抖音号/抖音号绑定的官方千川账户发送申请，从而获取投放权限。​
3.
可投商城——推商品下，商品的商城流量默认归属该商品所在店铺的人店一体抖音号或平台指定抖音号。商品所在店铺绑定的巨量千川账户使用该抖音号投放商品时，可投放到商城流量。如店铺未绑定人店一体抖音号或未被平台指定抖音号时，则该店铺的首个千川直投账户可投商城。​
授权链路​
账户管理进行投放授权操作，可进行发起、授权以及管理​
类型一：发起申请——非官方抖音号授权管理​
💡
适配类型：希望投放的抖音号并非当前账户的官方抖音号，可在此发起授权申请和查看授权相关信息。​
申请授权：需要得到该抖音号的授权确认，可在抖音号的官方千川账户或抖音APP站内信确认​
三步走：发起申请→填写信息→确认授权​
适用于目前使用的巨量千川账户如果要给自运营抖音号或合作达人抖音号投放商品全域投放，需要向该抖音号申请投放权限​
