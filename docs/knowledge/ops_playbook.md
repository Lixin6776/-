# 一、完整运营链路 SOP

## 1. 开播前（T-1 天 ~ 开播前 1 小时）

| 动作 | 依据 | 要点 |
| --- | --- | --- |
| 定 ROI 目标 | 官方：不要从低往高拉 | 参考系统建议 ROI；**切换净成交出价时按结算率折算后适当下调**，设太高会拿不到量 |
| 设预算 | 官方：按整场直播预算设置 | 全域是「超级计划」，**不要设小额预算再多次小幅上调**（影响跑量） |
| 素材组合 | 官方：种收一体 + 素材互相配合 | 补 2~3 条「开场有痛点、中段有机制」的新素材；复用高 ROI 老素材 |
| 计划结构 | 官方：全域是超级计划 | 全域开启后其他投放自动暂停；**同一抖音号只能一个千川账户投全域** |
| 直播时间块 | 官方 | **连续开播要勾选所有开播小时**，不能只勾开播/下播那两小时 |
| 素材探索期 | 官方 | 新素材探索期约 **3 日**，别急着判失败 |
| 大促节点 | 行业 | 提前 1~2 周抢跑，爆品追投不能停 |

## 2. 直播中盯盘（每 5 分钟）

**先看消耗在哪条计划**（用户确认 + 官方看数逻辑）

| 信号 | 判断顺序 | 动作 |
| --- | --- | --- |
| 消耗突然加快 | 先定位哪条计划在放量 | 用**一键控量**，不要卡预算/频繁起停 |
| 消耗突然变慢 | 先查预算是否撞线、计划是否在投 | 再看素材是否衰退 |
| ROI 持续回落 | 先降预算 | 止跌后新建追投 |
| 追投占比 > 25% | 官方建议 25% 左右 | 降追投占比，看基础消耗能否起来 |
| ROI 未达标 | 先看是否达到 10×CPA 累计消耗 | 没到就属探索期，别急着判失败 |

**官方红线（盯盘时不能碰）**：
- ❌ 用卡预算/频繁起停代替一键控量 → 反复冷启
- ❌ 频繁调整 ROI 目标（间隔需 ≥1h、幅度 ≤±10%）
- ❌ 骤然大量删除素材
- ❌ 随便删头部素材

## 3. 下播后复盘（自动生成）

复盘七段：**本场概况 → 数据拆解 → 流量结构 → 具体问题 → 解决方案 → 下场准备 → 优质直播间标准对照 → 历史对照**

**核心拆解公式**：
```
ROI = GPM ÷ CPM × 曝光观看率
  GPM  → 承接端效率（话术/机制/价格）
  CPM  → 流量端成本（人群竞争/素材质量）
  曝光观看率 → 素材与画面的吸引力
```

**基础 vs 整体拆分**（官方投放管理页）：
- 基础达标 + 整体不达标 → **调控拖累整体**
- 两者都不达标 → **基础投放本身有问题**

## 4. 素材产出（每日/每周）

| 动作 | 依据 |
| --- | --- |
| 每天保留至少一批新素材测试位 | 官方：素材互相配合，持续补充优质素材给系统探索 |
| 新素材前 3 秒直接上痛点+使用场景 | 官方优质素材标准 |
| 清理**持续多天低跑量**的低质素材 | 官方：单场 ROI 低不算低质 |
| 不要删高跑量低转化素材 | 官方：它承担跑量责任，删了整体 GMV 和 ROI 都会变差 |
| 想刺激某条素材起量 | 用**追投下调 ROI 目标**加速激活 |

# 二、判断阈值总表（全部有依据）

| 判断项 | 阈值 | 依据来源 |
| --- | --- | --- |
| ROI 是否达标 | 千川计划里的 ROI 目标（如 2.60） | 官方/计划 |
| **追投占比** | **> 25% 提示**；> 50% 严重超标 | ⭐ 官方《素材追投调控产品手册》 |
| **追投预算** | 计划预算的 **20~25%**，或 2~10 个转化成本，或 500~1000 元；首测 <500 元 | ⭐ 官方《商品投放调控任务说明》 |
| ROI 未达标是否正常 | 累计消耗 < **10 × CPA** 时属探索期 | ⭐ 官方 |
| 素材是否低质 | **持续多天低跑量**（不是单场 ROI） | ⭐ 官方《净成交出价-素材评估思路》 |
| 新素材探索期 | 约 **3 日** | ⭐ 官方 |
| 高消耗低效素材 | 消耗 > ¥500 且 ROI < 账户实际 ROI × 0.8 | 用户确认 |
| CPM / GPM / 曝光观看率 / 在线 / 转化率 | **对比账户自身历史中位**（偏离阈值才报） | 方案A（用户确认） |
| 内容竞争力诊断 | 系统诊断 **>20%** 由内容竞争力下降导致 | ⭐ 官方自查SOP |
| 店铺体验分 | **< 60 分**影响投放 | ⭐ 官方自查SOP |
| 起量时长 | 通常 **6 小时左右** | ⭐ 官方 |

# 三、官方红线清单（违反会失去保障/伤效果）

| 类别 | 禁止项 |
| --- | --- |
| **成本保障** | 调 ROI 目标间隔 <1h / 幅度 >±10% / 两次间隔 <15min → **不享受成本保障** |
| **追投** | 追投预算**不支持成本保障**；预算越高 ROI 波动越大 |
| **一键起量** | 一键起量预算**不支持成本保障** |
| **控量** | 不要用卡预算/频繁起停代替一键控量 |
| **预算** | 不要小额预算多次小幅频繁上调；不要设过大虚假预算（如 99999） |
| **素材** | 不要骤然大量删除；不要投后短期探索就删；不要随便删头部素材 |
| **调控** | 不要频繁调控 |
| **数据** | ⚠️ 全域投放场次，**罗盘分拆「付费/自然」的数据不准，勿参考** |

# 五、优质直播间标准（官方，复盘对照用）

**三大维度**：基础质量（声画）→ 人货场匹配 → 内容价值 & 交易价值

- **声音**：音质清晰无杂音、语速平稳、声画匹配
- **画面**：1080p、无抖动、**无大面积遮挡**、光线明亮、**无夸张美颜滤镜**
- **人货场**：主播造型匹配人设与货品、商品陈列有层次、背景整洁且与场景匹配
- **内容**：讲解形式多样、有用有趣
- **交易**：商品组合清晰、促销福利明确、售后保障到位

> 官方：优质直播间会获得**专属流量激励**，且在 ROI/GMV 上更有优势。

# 六、当前账户诊断（2026-10-07 实测）

| 直播间 | 整体 ROI | 基础 ROI | 目标 | 追投占比 | 结论 |
| --- | ---: | ---: | ---: | ---: | --- |
| 质润官方旗舰店 | 1.86 | 2.53 | 2.60 | 66.4% | 追投严重超标 + 基础略欠 |
| 二硫化硒洗发水 | 1.77 | 2.69 ✅ | 2.60 | 80% | 基础达标，**调控拖累整体 0.92** |

**核心问题**：两个直播间的**基础投放都不差**（2.53 / 2.69），但**追投/调控占比 66%~80%**，
是官方建议值（25%）的 **2.6~3.2 倍**，把整体 ROI 拉到了 1.77~1.86。

**首要动作**：把追投占比从 66~80% 降到 40% 以下，观察基础消耗能否接上。
