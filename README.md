# 直播运营助手

千川全域直播的**本机运营工具**：直播盯盘 + 直播复盘 + 素材分析 + 运营助手对话。

**默认只读**：只出数据、结论和建议；任何预算 / 出价 / 计划 / 素材的改动都要人工确认后才执行。

> 第一次用、只是想赶紧跑起来？看 **[三步上手.md](三步上手.md)**（装环境 → 填直播间 → 连数据源出报表）。

**开源、免费、随便用**：代码公开在 GitHub，任何人可以克隆到自己的 Windows 电脑上用；
数据只存在你本机（`.local/` 和 `backend/.env` 都不进仓库），作者不碰你的账户。

## 第一次在新电脑上跑起来

**最简单：双击 `安装依赖.cmd`** —— 它会检测 Python / Node / pnpm（缺了提示去哪装，
能用 winget 就自动装），然后装好后端和前端依赖，并生成 `backend/.env`。
装完双击 `启动直播运营助手.cmd` 即可。

想手动装、或者安装脚本跑不通，看下面的手写步骤：

```powershell
# 1) 拉代码
git clone https://github.com/Lixin6776/qianchuanzidongtoufang.git qianchuan-ai-assistant
cd qianchuan-ai-assistant

# 2) 后端依赖
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -U pip
.venv\Scripts\python -m pip install -e .

# 3) 前端依赖
cd ..\frontend
pnpm install
cd ..

# 4) 本地配置（.env 不进仓库，要从模板建）
copy backend\.env.example backend\.env
#   然后编辑 backend\.env，填直播间名称和账户 ID

# 5) 启动（后端 8000 + 前端 5173 + 数据源浏览器）
#    直接双击：启动直播运营助手.cmd
```

启动后打开 <http://127.0.0.1:5173>。
第一次连数据源时，如果弹出的 Chrome 停在千川登录页，**登录一次**即可（登录态会保留）。

## 换电脑时，哪些东西**不会**跟着仓库走

仓库里只有**代码 / 测试 / 文档**。下面这些都在本机、已被 `.gitignore` 忽略：

| 内容 | 位置 | 不搬的后果 |
| --- | --- | --- |
| 盯盘记录 / 复盘 / 运营对话 / 网站变更 | `.local/` | 新机器没有历史，从零开始 |
| 策略库（投放策略版本） | `backend/qianchuan.db` | 要重新建一次投放策略 |
| 本地配置（盯哪个直播间、账户 ID） | `backend/.env` | 不知道读哪个账户 |
| 大模型 Key | `.local/llm_config.json` | 运营助手对话不可用 |
| 飞书授权 | `.local/feishu_config.json` | 复盘 / 日报发不到飞书 |
| 飞书已发送记录、文档地址 | `.local/feishu_sent.json`、`.local/feishu_doc_urls.json` | 可能重复发送 |
| 千川登录态 | Chrome 用户目录 | 要重新登录一次 |

**想连历史一起搬**：把 `backend/.env`、`backend/qianchuan.db`、整个 `.local/` 三个复制到新电脑对应位置即可。
（`.local/` 里含账户数据，只能自己拷，不要提交到仓库。）

## 一键启动脚本做了什么

`启动直播运营助手.cmd` → 调 `start.ps1`：

1. 后端 8000：没起就起，并等端口就绪
2. 前端 5173：没起就起
3. 数据源（调试浏览器 9222）：交给后端「连接数据源」逻辑（需要时会拉起 Chrome）
4. 检查盯盘状态：发现断开且"本该在跑"就自动恢复

已在跑的部分会跳过，可以重复双击。
日志在 `.local/logs/`。

## 常见问题（FAQ）

**这是干什么的？**
把巨量千川「全域投放 · 直播间」的盯盘 / 复盘 / 素材分析，做成本机的一个网页工具：
每 5 分钟读一次数据、出报表、发现问题、给调整建议，并沉淀操作日志和复盘。

**它会自己改我的计划吗？**
不会。**默认只读**：只出数据、结论和建议。任何预算 / 出价 / 计划 / 素材的改动，都要你人工确认。
当前版本连"确认后执行"都还没开，纯粹是看数据和给建议。

**要登录千川吗？**
要，而且只登录**你自己**的账户。工具通过本机 Chrome 的调试端口读你已登录的千川大屏页面，
登录一次会记住（存在 Chrome 的用户目录里）。

**我的数据会被上传到哪吗？**
不会。数据只写在你本机：`.local/`（盯盘记录 / 复盘 / 对话）和 `backend/.env`（配置），
这些都被 `.gitignore` 挡住，不进仓库、也不发给任何人。

**免费吗？能用在自己号上吗？**
免费，MIT 许可，随便用、随便改。工具跑在你自己电脑上、读你自己的账户，
和作者的账户没有任何关系。

**支持哪些平台？**
目前只做**巨量千川「全域投放 · 直播间」**（抖音电商直播）。别的投放场景没有适配。

**Mac / Linux 能用吗？**
暂时**只支持 Windows**（启动脚本是 PowerShell / cmd，读数据走 Windows 的 Chrome）。

**一定要有 Chrome 吗？**
要。工具靠本机 Chrome 的**调试端口（9222）**读千川页面，必须装 Google Chrome。

**Python 明明装了，却提示"检测到 python 但跑不起来"？**
大概率是 Windows 商店的**占位 python**（`Get-Command python` 能找到，但根本跑不了）。
去 python.org 装 3.11+，安装时勾上 **Add to PATH**，重开「安装依赖」。

**不填大模型 Key，能不能用？**
能。**盯盘报表、复盘、素材分析都是规则算出来的，不需要大模型。**
大模型只用在「直播运营助手」的**对话**上（比如你直接问它问题）；不填就是聊不了天，其它照常。

**我有好几个直播间 / 账户，能一起盯吗？**
一版工具同时盯**一个**直播间。要换就启动后在「数据源」窗口里改直播间名和账户 ID。

**能自动跑，不用我一直开着窗口吗？**
后端服务在后台跑就行（关掉浏览器标签页没关系），但**电脑不能关机 / 睡眠**——
关机会中断盯盘（下次打开会自动接着跑，但要重新连一次数据源）。数据源断了工具会尽量自动重连。

## 常用排查

| 现象 | 处理 |
| --- | --- |
| 面板显示「数据源：未连接」 | 点「连接数据源」；提示要登录就在弹出的窗口登录千川 |
| 数据不动 | 工具会**自动刷新大屏并复查**；确认真停了会提示 |
| 复盘 / 日报没收到 | 检查飞书是否授权（「飞书」窗口） |
| 运营助手不回答 | 检查「大模型」窗口的 Key 配置 |

## 目录结构（简述）

```
backend/app/
  api/            HTTP 接口（chat / live_watch / ops_chat / reviews ...）
  execution/cdp/  读千川页面（大屏、素材、平台日志）
  services/       盯盘、复盘、素材分析、诊断引擎、自检、运营助手
frontend/src/     界面（直播盯盘、运营助手对话、复盘、素材分析）
docs/knowledge/   官方规则 / 运营手册 / 方法论（抓取整理）
.local/           本机数据与配置（不进仓库）
```
